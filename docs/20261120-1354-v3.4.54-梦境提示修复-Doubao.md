# v3.4.54 梦境碎片提示修复（2026-11-20 13:54）

## 问题（来自玩家截图）

「樱花倒着飘的夜晚」梦境里，点击「美术室」后出现两个可见问题：

1. 居中提示条 `✦ 梦境碎片：dream_shard_sunian` 正好压在场景正文上，把「背面也是画」等文字遮住；
2. 提示直接暴露内部存档 ID（`dream_shard_*`），破坏沉浸感；
3. 连续点击不同场景时，每张场景卡都叠在同一中心，旧卡不会关闭。

## 根因

- `js/engine.js` 的 `flashHint()` 固定在 `top:50%; left:50%; translate(-50%,-50%)`，与任何居中弹层必然重叠。
- 梦境收集分支把 `sc.shard.id` 拼进提示，而不是 `sc.shard.text`。
- `enterDream()` 每次点击都新建场景卡，没有保存/关闭上一张的引用。

## 修复

- `flashHint(text, duration = 1200)`：
  - 改为顶部居中 `top:88px`，宽度上限 `min(760px, 100vw - 48px)`，自动换行、居中，不再压住正文；
  - 增加可选停留时长，默认 1200ms 不变。
- 梦境碎片提示：改为 `✦ 梦境碎片：${sc.shard.text}`，停留 2600ms，让玩家读完；不再输出内部 ID。
- 梦境场景卡：新增 `activeSceneCard`，打开新卡前先移除旧卡；关闭时清空引用。同一时刻只保留一张卡。
