> 2026-10-25 · GLM

## 问题与方案

无 CI 后「忘跑测试就 push → 3 分钟后 cron 把坏版本上线」无任何拦截。方案（零依赖，不引 CI）：

- `.githooks/pre-push`：push 前自动 `npm test` + `test:syntax` + `git diff --check`；
  `PREPUSH_E2E=1 git push` 时追加 e2e（约 7 秒）；
- `tools/setup-hooks.sh`：新机器 clone 后执行一次（`git config core.hooksPath .githooks`）；
- `tools/bump_version.py`：engine.js 头注释缺当前版本行时打印 ⚠️ 提示（手工补，不自动生成）。
