# v3.4.1 · 发行准备：itch 打包脚本 + 反馈入口

## 改动

1. **`tools/pack-itch.sh`**：一键打分发 zip（index/manifest/sw/favicon/css/js/fonts/icons/assets，
   剔除 docs/tests/tools/audio 之外零遗漏），输出 `dist/sakura-letters-v<VER>-itch.zip`（实测 2.3MB），
   附 itch.io 上传建议（HTML5 嵌入 1280×800、mobile friendly）；
2. **反馈入口**：「关于」页加 gitee issues 链接（提示附标题页右下角版本号）。

## itch.io 上传步骤（一次性，需你操作）

1. 注册 itch.io → Create new project → Kind of project: HTML → Upload zip；
2. 嵌入参数：Viewport 1280×800、Fullscreen button 勾选、Mobile friendly 勾选；
3. 封面用 `assets/og-cover.jpg`（630×315 缩放即可）；
4. 页面文案（可直接用）：
   「樱时信笺 · Sakura Letters——以写信 / 回信为核心的视觉小说。校园群像 + 时间循环 +
   多结局。帮助三位女主角走出各自的困境，在樱花祭之夜写下属于你的回信。」
5. Classification: Soundtrack 无（BGM 内嵌）；启用 itch.io app 保护可关。

## 验证

- `bash tools/pack-itch.sh` 实测出包 2.3MB；解包核对含 sw.js（itch iframe 支持 SW 需 https，
  itch 默认满足；若 SW 在 iframe 内受限，游戏主体功能不受影响——离线缓存退化为浏览器缓存）。
- 「关于」页反馈链接渲染 ✓；npm test 42/42。
