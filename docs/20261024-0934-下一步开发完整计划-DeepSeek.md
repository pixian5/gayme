# 下一步开发完整计划（DeepSeek）

日期：2026-10-24 09:34 · 模型：DeepSeek · 基线版本：v3.3.9

> 本计划是「下一步待实现」的展开版：把后续所有可做的方向拆成**分阶段任务清单**，
> 每项标注目标文件/模块、验收标准、成本、依赖与建议版本号，便于逐版推进与验收。

## 0. 现状与总体原则

- **项目**：樱时信笺 · HTML5 视觉小说，纯前端零构建；主项目 AtomGit（origin），GitCode 备份；
  服务器 root cron 每 3 分钟自动拉取部署（本地测试为唯一门槛）。
- **完成度**：剧情主线+后日谈+学姐线 441 节点；12 结局 + 学姐 SIDE；CG 11 张；
  92 种互动（89 GameKit 玩法 + 3 基础小游戏）；存档/图鉴/性格画像/记忆系统齐全。
- **质量基线**：静态 42 项 + e2e 7/7 全过；自 v3.3.3 起建立「数据契约测试」体系。
- **原则**：每版 +0.0.1（满十进一）；开发测试版**无需兼容旧存档**（先备份旧数据即可重构）；
  代码加中文注释；每版完成必须 `npm test` + `test:syntax` + `test:e2e` + `git diff --check` 全过再提交推送。

## 4. 里程碑与依赖

- **M1（体验闭环）**：Phase 1 完成后，键盘可全流程通关、图鉴可看大图、存档可单槽迁移。
- **M2（内容闭环）**：Phase 2 完成后，loopText 覆盖 ≥120 节点、回响可查看。
- **M3（素材可插拔）**：Phase 3 引擎管线就绪后，素材到位即可「替换即上线」。
- **M4（对外发布）**：Phase 4 完成分发与可选多语言。
- **依赖**：P3-3/4 依赖素材（用户提供）；P3-5/P4 依赖用户拍板；P4-3 依赖反馈。

## 5. 风险与回退

- **无素材时**：程序化 BGM + SVG 立绘继续可用（当前实现即兜底），素材接入为「增强」而非「阻断」。
- **token/远程异常**：AtomGit 与 GitCode 互为镜像，任一可用即不丢提交；每版本地测试为硬门槛。
- **工作区回退**：开工先 `git fetch` + 比对 `HEAD`/`origin/main`，必要时 `reset --hard origin/main`。
- **重构风险**：开发测试版允许不兼容旧存档，但改动前**先导出/备份旧数据**（设置面板已支持导出 JSON）。

## 6. 不可破坏的约束（继承）

1. 全量 `npm test` + `test:syntax` + `test:e2e` + `git diff --check` 通过才可停止
2. 叙事回溯仅保留 `d5_rewind`、`d15_rewind` 两处，且必须带 `timeLoop: true`
3. 真结局条件：三女主 GOOD 全通 → `true_unbroken`；合成樱花信并破环 → `true_end`；后日谈只由 `true_end` 解锁
4. 非回溯剧情边的日期与时段必须单调前进
5. 学姐不被召回樱海、不解释循环机制
6. 版本号每次 +0.0.1，满十进一
7. 每版完成：更新版本 → 跑全量测试 → 浏览器回归 → 写 docs → 中文 commit + push
8. 主项目 AtomGit（origin），GitCode 为备份 remote
