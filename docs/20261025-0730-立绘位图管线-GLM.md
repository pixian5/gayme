# v3.4.0 · 立绘位图管线（引擎先行，素材可插拔）

> 2026-10-25 · GLM

## 机制

- `assets/portraits/<id>.webp`（竖版 2:3，≤150KB）——文件存在且 id 登记于
  `engine.js` 的 `PORTRAIT_BITMAPS` 清单 → 立绘渲染为 `<img>`（object-fit: contain 底部对齐）；
- 清单为空 / 文件缺失 → 自动回退内联 SVG（当前 v3.1.0 手绘版继续生效）；
- `direct.js` 触觉关怀立绘同步接入（经 window.__PORTRAIT_BITMAPS）；
- SW 预缓存预留注释位：素材上线时追加 assets/portraits/*.webp。
