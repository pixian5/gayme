# v2.7.5 互动层推进保护

## 问题

第 2 日图书馆剧情在对白节点触发涂鸦时，涂鸦层已经覆盖页面，但对白框仍留在 DOM 中并可被点击。连续点击对白会绕过涂鸦提交，直接推进到下一节点；梦境层也有同样风险。

## 修复

- `advance()` 与自动模式在推进前统一检查 `hasActiveInteractionLayer()`。
- 梦境、涂鸦层创建时隐藏对白框。
- 互动层仍由各自的提交按钮负责完成，提交后才允许进入剧情下一节点。

## 验证

在 `http://127.0.0.1:4173/?v=2.7.5&regression=guard` 进行真实浏览器回归：

- 第 1 日星图按“信·起笔 -> 北辰 -> 信·落笔 -> 樱·右瓣 -> 心 -> 樱·左瓣”完成，进入第 2 日。
- 选择“图书馆（林诗雨）”，触发涂鸦层后对白框数量为 0。
- 对涂鸦层连续点击 5 次仍停留在 `.doodle-layer`，提交按钮仍存在。
- 实际画线并点击“✦ 完成”后才进入 `d2_library_9` 后续对白。
- 浏览器 error/warning 日志为空。
