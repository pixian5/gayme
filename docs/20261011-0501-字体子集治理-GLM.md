## 二、交付的工具链（tools/）

| 脚本 | 作用 |
|---|---|
| `tools/collect_font_charset.py` | 扫描 index.html + css/*.css + js/**/*.js 收集实际字符集（补 ASCII 与常用标点），输出 /tmp/font_charset.txt |
| `tools/check_font_coverage.py` | 对比字符集与两个 woff2 的 cmap，报告缺失（自动排除 emoji 类符号回退），有缺失时 exit 1 |
| `tools/rebuild_font_subset.sh` | 一键重建：下载源字体（约 23MB，**脚本头有热点警示**）→ pyftsubset 裁剪两字重 → 自动复查覆盖 |

## 三、待办（WiFi 环境下一行命令）

```bash
bash tools/rebuild_font_subset.sh
```

完成后 `check_font_coverage.py` 输出「覆盖完整 ✓」即可提交。若新文案再引入未覆盖汉字，
同一条命令即可增量修复（子集按最新字符集重裁）。
