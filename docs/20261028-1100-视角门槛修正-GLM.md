# v3.4.23 · 视角门槛修正（互斥记忆数组）

> 2026-10-28 · GLM

## 问题（自查 v3.4.20 的 12 段视角时发现）

苏念的三个视角节点（d2_art_3 / sn_5 / sn_13_good）门槛借用了**林诗雨的**记忆
（`序章·诗雨`、`诗雨·走廊`）——逻辑错配：想看苏念的内心，却要先解锁诗雨的回忆。

根因：记忆库中**苏念没有「必经路径」的专属记忆**，她的记忆都是可选产物
（`苏念·海报·取景` 取决于拍照玩法得分，`苏念·一笔·用力/安静` 互斥二选一）。

## 修复

1. **引擎**：`requiresMemoryId` 支持数组——任一记忆解锁即可通过门槛；
2. **苏念三处**改为 `["苏念·海报·取景", "苏念·一笔·用力", "苏念·一笔·安静"]`——
   三条里解锁任意一条（无论拍照得分高低、涂鸦画得用力还是安静）都能看；
3. **契约**：门槛记忆存在性检查支持数组写法。

## 验证

- 静态 45/45；全图走查 441 节点 0 坏；e2e 通过；
- 实机：未解锁任一记忆 → 👁 不出现；解锁 `苏念·一笔·安静` 后 → 👁 出现，
  点击显示「❝ 内心独白 ❞ 苏念 他问「什么是你」的时候…」✓
