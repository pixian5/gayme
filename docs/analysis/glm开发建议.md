> 当前版本：v2.7.7

## 二、剧情完整梳理

### 2.1 序章 · 第 1 日（共通线开场）

主角 **沈屿** 因父母冷战三个月、父亲工作调动，选择住校转入 **樱海学园**。

- 走廊被 **林诗雨**（高二(3)班班长、黑长直、优等生）叫住 → 关键词「林诗雨」
- 教室里发现她地图边角写着「角色 A 推开门——」→ 关键词「角色A」
- 操场被 **夏织**（田径社王牌）强拉入社 → CG `cg_meet_xiazhi`、好感 +1
- 迷路闯进美术室遇见 **苏念**（淡紫渐变头发，对着紫色画布发呆）→ 关键词「紫」、CG `cg_meet_sunian`
- 校门口书包里出现 **匿名信**（樱花瓣形状）：「第一个周末，请你做一个选择。樱海有三条未走完的路，你会走哪一条？」→ 关键词「匿名信」、CG `cg_letter`

### 2.2 共通线 · 第 2 日（路线初探）

`d2_choice` 玩家自行选择上午去哪：

| 选项 | 触发节点 | 揭示的角色秘密 | 关键 flag |
|---|---|---|---|
| 图书馆 | `d2_library_*` | 林诗雨偷写小说，家里要她考法律系，小说写给去世的外婆 | `flag_shiyu_secret`、`flag_shiyu_grandma` |
| 操场 | `d2_field_*` | 夏织备战全国赛，特招名额压力，妈妈再婚后家不像家 | `flag_xiazhi_family` |
| 美术室 | `d2_art_*` | 苏念的紫色是亡兄最爱，省展金奖后卡稿三年 | `flag_sunian_block`、`flag_sunian_brother` |
| 天台 | `d2_rooftop_*` | 风吹来便条「学姐也是转学生」→ 关键词「学姐」 | — |

**彩蛋分支**（仅在多周目触发）：
- `d2_loop_memory`：在樱花树下听见风说话，提示「循环不是用来逃的，是用来写的」
- `d2_loop_senior` / `d2_senior_easter`：学姐直接登场，剧透合成配方：「祭信 = 樱花祭 + 回信」「未寄信 = 匿名信 + 学姐」「樱花信 = 祭信 + 未寄信」

**中午食堂** `d2_noon`：三人同桌，提及苏念去年到运动会看了一眼就走，暗示三人早有交集。

**晚上** `d2_dreamweave`：进入梦境编织玩法。

### 2.3 共通线 · 第 3 日（运动会预选）

`d3_choice` 上午帮谁：
- 帮诗雨整理报名表 → 她写到「女子 100 米」时停顿（暗示夏织）
- 陪夏织热身 → 揭示左脚旧伤 `flag_xiazhi_injury`
- 去美术室叫苏念 → 她说「去年看一个人跑，她摔了，我没看完就走了」（三人旧事伏笔）

下午预选赛：夏织 60 米处左脚一软，第二名冲线。诗雨拿冰袋、苏念抱画本，三人都到场边。**这是三人关系的第一次显性聚拢**。

晚上 `letter_1` 收到第二封匿名信：「当一个人明明在跑，却越跑越累，是该让她继续，还是让她停一停？」玩家三选一回信。

`d3_season` 季节切换玩法，`d3_rubbing` 拓印玩法（v1.4.0）。

### 2.4 共通线 · 第 4 日（信件与静夜）

`d4_puzzle` 信物拼图：把撕碎的匿名信拼回，三种拼法暗示「樱信·夜名 / 樱信·无名 / 夜樱·信名」——指向学姐署名。

`d4_breath` 呼吸引导、`d4_fold` 信纸折痕、`d4_tealeaf` 茶渍占卜、`d4_shadow` 影子对位、`d4_candle` 烛火守阵、`d4_phone` 旧电话拨号、`d5_perfume` 调香 —— 一连串夜话玩法，主角开始内省。

`letter_2` 第三封匿名信。

### 2.5 第 5 日 · 路线分岔（关键节点）

`common_day5_morning` → `d5_route_check`：

> 第 5 日午后。海风把樱花吹成一场粉色的雨。

玩家**明确选择**周末去见谁（v2.7.7 之前是按好感静默抢占路线，现已改为显式选择）：

- 图书馆找林诗雨 → `route_shiyu_1`
- 操场找夏织 → `route_xiazhi_1`
- 美术室找苏念 → `route_sunian_1`

### 2.6 三条个人线（4 章 × 3 结局）

#### 2.6.1 林诗雨线 · 写作与回头

| 节点 | 内容 |
|---|---|
| `route_shiyu_1` ~ `sy_5` | 诗雨母亲翻了书包没骂她，反而做了一桌菜（更可怕）。半夜私信玩家（v0.5.0 收件箱）：「我不知道该写下去还是停下来。」 |
| `sy_minigame` | writing 玩法，替她写一句开场 |
| `sy_choice_1` | 三选一决定路线走向 |
| GOOD `sy_10_good` ~ `sy_ending_good` | 「让她回头之后，开始活下去」→ 她连夜写完投了校刊，第 35 日样书封面印着笔名，母亲哭着说「再写一本」。结局「回 头」 |
| NORMAL `sy_10_normal` ~ `sy_ending_normal` | 「先写完半章再决定」→ 半章稿子放进外婆旧书箱，答应考完法律系再写。结局「半 章」 |
| BAD `sy_10_bad` ~ `sy_ending_bad` | 「也许她真的该消失一次」→ 一周后雨天转学去北方读法律系。结局「未 活 过」 |

**核心弧光**：从「不写就会忘掉自己」到「敢回头看见自己开始活下去」。BAD 不是死亡而是更隐痛的「活成别人想要的样子」。

#### 2.6.2 夏织线 · 跑步与等待

| 节点 | 内容 |
|---|---|
| `route_xiazhi_1` ~ `xz_6` | 教练辞退她（发挥不稳定、特招名额）；父亲童年带她练跑摔出旧伤，母亲再婚后那不是她的家；半夜私信问「我还有戏吗？」 |
| `xz_minigame` | running 玩法 |
| `xz_choice_1` | 三选一决定路线走向 |
| GOOD `xz_10_good` ~ `xz_ending_good` | 「我陪你。一直陪你到终点线」→ 一个月后跑进 11.8，全国赛第二名撞线。结局「终 点 线」 |
| NORMAL `xz_10_normal` ~ `xz_ending_normal` | 「我帮你练，但要先去治脚」→ 静养一个月，全国赛第三，留校复读一年。结局「第三名」 |
| BAD `xz_10_bad` ~ `xz_ending_bad` | 「你不需要别人陪」→ 全国赛前一周雨中独自加练摔伤，韧带拉伤休学回父亲那边。结局「一 个 人」 |

**核心弧光**：从「跑出去才能逃离」到「跑出去和有人等着可以同时发生」。BAD 揭示「一个人从来不是她想要的」。

#### 2.6.3 苏念线 · 紫色与挣脱

| 节点 | 内容 |
|---|---|
| `route_sunian_1` ~ `sn_5b` | 省展邀请函已到，她撕了 47 张草稿。涂鸦玩法让玩家画一笔「她是谁」（v0.5.0 涂鸦） |
| `sn_6` ~ `sn_9` | 紫色是亡兄最爱，她画紫是想留住他。画布里藏着「想从紫里挣出来的人」→ 关键词「挣」 |
| `sn_minigame` | painting 玩法（调色） |
| `sn_choice_1` | 三选一决定路线走向 |
| GOOD `sn_10_good` ~ `sn_ending_good` | 「松手。让她出来」→ 一个月画完《挣》，省展入口第一幅。结局「挣」 |
| NORMAL `sn_10_normal` ~ `sn_ending_normal` | 「先在网络开个小展试试」→ 退回省展邀请，开小站贴卡了三年的草稿，第一条留言「我也卡在草稿里三年」。结局「网 展」 |
| BAD `sn_10_bad` ~ `sn_ending_bad` | 「也许她本来就不该出来」→ 画布翻面，交还钥匙休学。结局「按 住」 |

**核心弧光**：从「天才卡在草稿里」到「松开按住自己的那只手」。NORMAL 把天才叙事解构成「我也这样」的共鸣，是本项目最克制、最成熟的分支。

### 2.7 第 6 ~ 15 日 · 长玩法链与时间回溯

三条个人线结束后，剧情**并不直接进入真结局**，而是进入一段「她」（后来在 `d6_sandglass` 揭示为学姐）引导的长玩法链：

- 第 6 日：沙漏、风筝、密码锁、折纸
- 第 7 日：星轨、萤火虫、风铃、河灯
- 第 8 日：电报、天平、钟摆
- 第 9 日：节拍器、星图、风车、织布、镜面
- 第 10 日：灯笼、波纹、马赛克、碑帖、琴弦、日蚀、印章、星盘
- 第 11 日：万花筒、算盘、齿轮、等高线
- 第 12 日：日晷、染缸、风车、编织
- 第 13 日：镜面、灯笼、波纹、马赛克、碑帖
- 第 14 日：星轨、鼓点、风向标、漏刻、拼图、棋局、旗阵
- 第 15 日：旗阵辨识 → `d15_rewind` **时间回溯** → 第 5 日清晨

**叙事功能**：这一段是「循环」机制的可视化。学姐在每段玩法里说一句「她想说的不只是 X」，但从不直接揭晓。`d6_sandglass` 的文本「你第一次确定长玩法里那个反复出现的『她』就是她」是关键揭破点。

**回溯后**：`d5_loop_arrival` / `d5_loop_choice` 三选一（写背面 / 等她叫 / 读落款），三条分支都汇入 `d5_mimic` 声音模仿玩法。`d5_loop_letter`、`d5_loop_signature` 是 v2.6.9 新增的承接节点，确保第 15 日回溯到第 5 日有文本承接而非断链。

### 2.8 真结局路径

#### 2.8.1 真结局前章 `true_unbroken`（LOOP ENDING · 未 破 环）

进入条件：三位女主 GOOD 全通。
节点 `true_end_entry` → `true_2` 学姐署名信揭破身份 → `true_3` 「三年前我也是转学生，三条路都走了一半，最后休了学」→ `true_5` 樱花祭之夜请你替她回信 → `true_choice` 三选一。

**关键设计**：三个普通选项都通向 `true_6` → `true_ending`，但只解锁 `true_unbroken`（循环仍在等待最后一步）。**真正打破循环的隐藏选项**：

```
★ 「樱花信」—— 把祭信与未寄信合在一起 ★
requires_compose: "樱花信"
```

必须先合成「樱花信」才能选此项。

#### 2.8.2 真结局 `true_end`（TRUE ENDING · 樱 花 信 · 破 环）

`true_break_loop` 学姐：「你做到了。这封信，我等了三年。」
`true_break_4` 自由书写信件（玩家自己打字），按关键词走 `true_break_5a/b/c/d` 四种回应。
`true_break_ending` 文本：「这一次，樱花不会再倒着飘了。」

### 2.9 后日谈 · 樱海以后

真结局完成后开放。这是一段从「樱花祭之夜」延伸到「毕业前」的长收束，每段时间都配一个分类/排序/书写玩法：

| 时间 | 节点 | 玩法 | 主题 |
|---|---|---|---|
| 樱花祭后 3 天 | `afterword_entry` ~ `afterword_three` | — | 学园收摊，三人约好每周见一次；沈屿给冷战中的父母各发一条近况 |
| 同期 | `afterword_postcard` | 明信片印记（4 选 2，4 种组合 + 兜底） | 学姐寄来明信片，玩家替她补两枚印记 |
| 一周后 | `afterword_reply` | 自由回信（4 种关键词分支 + 默认） | 学姐回信「我在新城市打开了一扇窗」 |
| 同期 | `afterword_timeline` | 时间线排序（4 事件） | 把樱花祭、收摊、收信、今天排顺序，正确错误都不阻断 |
| 半年后（秋） | `afterword_autumn` ~ `afterword_mailbox_reply` | 自由回信（3 种 + 默认） | 校内公告栏改「回信角」，回第一张公开纸条 |
| 同期 | `afterword_mailbox_rules` | 三选一规则 | 署名日期 / 先问需要 / 允许空白 |
| 同期 | `afterword_mailbox_triage` | 回信分拣（3 对 3 匹配） | 空间 / 一步 / 倾听 |
| 又过半年（毕业前） | `afterword_wall` | 留言墙整理（4 张纸条分 3 桶） | 公开回应 / 交还本人 / 暂不张贴 |
| 同期 | `afterword_proofread` | 校刊校对（6 句分 3 桶） | 已有依据 / 只能推测 / 交还本人 |
| 终点 | `afterword_ending` | — | 「故事没有被封存——它只是终于交还给了每一个正在生活的人。」 |

**核心母题**：关怀不是替别人做决定。后日谈的每个玩法都在反复练习「先确认谁有决定权」「把知道的和不知道的分开」「不把猜测写成事实」。

### 2.10 关键词合成系统

```
樱花祭 + 回信   → 祭信
匿名信 + 学姐   → 未寄信
紫     + 挣     → 挣紫
小说   + 角色A  → 她就是我
全国赛 + 特招   → 她的选择
学姐   + 回信   → 替她回
祭信   + 未寄信 → 樱花信 ★ 破环钥匙
```

合成系统把传统关键词收集从「收集」转成「创造」，并且只有合成「樱花信」才能解锁真结局。这是本项目最核心的元玩法。

## 三、角色弧光与主题分析

### 3.1 三女主的共同结构

三人都是「卡住的人」：
- 诗雨卡在「写完 = 必须证明下一本更好」
- 夏织卡在「跑出去 = 必须离开现在的家」
- 苏念卡在「画完 = 必须放下哥哥」

主角沈屿的作用不是「替她们走完」，而是「在她们卡住的时候递一句话」。学姐在 `d2_senior_easter_3` 的台词是全剧总纲：

> 诗雨的小说，写下去比写完重要。夏织的脚，停下来比跑出去重要。苏念的紫，松手比画完重要。

### 3.2 学姐的元叙事功能

学姐是「三年前的沈屿」。她走了一半就休学，留下匿名信等一个能走得比她远的人。她在第 6~15 日的长玩法链里以「她」的身份出现，是循环机制的引导者，也是沈屿的镜像。

**关键设计**：真结局不是「打败循环」，而是「替学姐回她没敢回给自己的那封信」。合成配方的两条线——
- 祭信 = 樱花祭 + 回信（替别人回信）
- 未寄信 = 匿名信 + 学姐（替自己回信）

——对应了学姐在 `d2_loop_senior_3` 的提示：「一样要你替别人回信，一样要你替自己回信」。

### 3.3 后日谈的母题递进

| 玩法 | 母题 |
|---|---|
| 明信片印记 | 不问归期，只说今天 |
| 自由回信 | 不替对方决定终点 |
| 时间线排序 | 确认发生过的事有先后 |
| 回信角规则 | 关怀的边界 |
| 回信分拣 | 给空间 / 缩一步 / 先倾听 |
| 留言墙 | 公开之前先问写下它的人 |
| 校刊校对 | 把知道的和不知道的分开 |

后日谈不是「结局后的花絮」，而是把真结局的「替她回信」转化为一种可练习的日常伦理。这是本项目最独特的部分。

## 四、开发建议

### 4.1 剧情 / 叙事层面

#### P0 · 必须做

1. **沈屿的家庭线收束不足**。序章提到父母冷战三个月、母亲说「随你便」，但直到 `afterword_entry` 才有一句「我给父母各发了一条近况……冷战终于有了第一道缝」。建议在共通线第 3~5 日增加 1~2 段沈屿夜里给父母发消息但没发出的独白节点，让后日谈那道「缝」有铺垫。

2. **三女主之间的旧交待不明**。`d2_noon_9` 诗雨说苏念「去年看了一会儿就走了」、`d3_sunian_5` 苏念说「去年看一个人跑，她摔了，我没看完就走了」——这是三人旧关系的核心伏笔，但从未正面展开。建议在第 6~15 日长玩法链中插入 1 个回忆节点（例如 `d8_old_photo`），用一张旧照片明确三人初中时的交集，避免「三人之间是有故事的」沦为旁白空话。

3. **学姐在第 6~15 日的「她」身份揭破后戏份稀薄**。`d6_sandglass` 之后学姐基本退场，直到真结局才回来。建议在长玩法链中段（第 10 日左右）加一个学姐「差点说漏嘴」的节点，强化玩家对循环存在的怀疑。

#### P1 · 建议做

4. **BAD 结局的情感强度差异**。诗雨 BAD（转学读法律系）和夏织 BAD（韧带拉伤休学）有明确悲剧，但苏念 BAD（画布翻面、交还钥匙）相对平淡。建议补 1 段苏念离开前在画室留下一张字条的节点，让 BAD 也有「她留下了什么」的余韵。

5. **第 6~15 日长玩法链叙事疲劳风险**。40+ 玩法连续推进、每段都是「她说——」句式，玩家容易跳过文本。建议把长链拆成 3 个小章节（第 6~8 日「旧物」、第 9~11 日「节奏」、第 12~15 日「归位」），每章开头加一段沈屿的独白作为呼吸点。

6. **NORMAL 结局的可追忆性**。三条 NORMAL 都不是失败而是「另一种活法」，但当前玩家很可能直奔 GOOD。建议在流程图里给 NORMAL 加一句副标题（如「她留下了半章，也留下了自己」已经够好），并在 CG 图鉴里给 NORMAL 也配一张图（当前只有 GOOD 有 CG）。

#### P2 · 可选

7. **多周目引导提示**。真结局需要三周目（至少三个 GOOD），但游戏内没有显式提示「你需要再开一周目走另一条路」。建议在第一次打出 GOOD 后，在标题画面增加一行小字「还有两条路没走完」。

8. **学姐视角番外**。学姐是元叙事核心，但玩家始终从沈屿视角看。可考虑在真结局完成后解锁一段「三年前的学姐」番外，复用现有玩法但换视角，成本低且能补全世界观。

### 4.2 玩法 / 系统层面

#### P0

1. **玩法结果对剧情影响过弱**。40+ 玩法仅通过 `add.affection` 和 `personality` 影响数值，没有实质性分支。建议把至少 3 个关键玩法（如 `d15_flag` 旗阵、`d4_puzzle` 拼图、`d5_perfume` 调香）的完美/失败结果绑定到后续节点的不同文本，让玩家感觉「玩得好 vs 玩得差」有叙事差别。

2. **关键词合成系统扩展不足**。7 个合成配方里只有「樱花信」是破环钥匙，其余 6 个（挣紫、她就是我、她的选择、替她回 等）合成后没有任何反馈。建议给其余 6 个合成物各加一段「合成回忆」节点（可放入回忆图鉴），让合成不只是真结局的门票。

3. **朋友圈 / 收件箱深度不够**。`MOMENTS` 池和 inbox 系统已实现，但当前只在 `sy_5`、`xz_6` 等少数节点触发。建议给每条个人线增加 2~3 条朋友圈互动，让三女主在玩家不在场时也有「生活感」。

#### P1

4. **玩法同质化**。大量「拖动到目标 / 在目标时刻停 / 选对那个」类玩法机制重叠。建议下一批玩法引入：
   - 多步骤推理（如把拼图 + 旗阵 + 棋局合成一个连续谜题）
   - 玩家输入文本影响后续（当前只有 `letter` 自由书写，可扩展到日记/便签）
   - 角色协作玩法（让两位女主同时在场，玩家选择谁主导）

5. **存档/读档体验**。当前 6 槽位 + 自动存档，但缺少「快速保存」「快速读取」快捷键。建议绑定 F5/F9 或在顶部菜单加快捷按钮。

6. **流程图可读性**。流程图已实现，但 4211 个节点的全图不可读。建议按章节分页（序章 / 共通线 / 三条个人线 / 长链 / 真结局 / 后日谈），并提供搜索框。

#### P2

7. **成就系统**。当前只有结局图鉴和 CG 图鉴，建议增加「隐藏成就」（如「第一次合成樱花信」「三周目内打通三 GOOD」「后日谈全玩法完美」），延长游戏寿命。

8. **跳过已读**。`skipMode` 已实现，但跳过速度受 typewriter 限制。建议对 `visitedNodes` 已记录的节点提供「瞬时跳过」选项。

### 4.3 技术 / 工程层面

#### P0

1. **`engine.js` 17939 行单文件，严重违背可维护性**。建议按职责拆分为 ES Module：
   ```
   js/engine/
     state.js          # 游戏状态机
     router.js         # 节点路由 / gotoNode
     render.js         # 渲染（背景/立绘/对话框）
     choices.js        # 选项 / 信件 / 自由书写
     minigame-router.js# 玩法分发（40+ 玩法）
     particles.js      # 粒子层
     bgm.js            # 音频
     ui.js             # 顶部菜单 / 浮层 / 流程图
     save-bridge.js    # 与 saves.js 的桥接
   ```
   拆分后用 `<script type="module">` 加载，或保留 IIFE 但分文件。**这是后续所有改动的地基**。

2. **`script.js` 4211 行单文件维护困难**。建议按章节拆分：
   ```
   js/script/
     characters.js     # CHARACTERS / PORTRAITS / SCENE_LABELS
     keywords.js       # KEYWORDS / COMPOSE_RECIPES
     cgs.js            # CGS / ENDINGS
     prologue.js       # 序章 + 共通线 Day 1~5
     route_shiyu.js    # 林诗雨线
     route_xiazhi.js   # 夏织线
     route_sunian.js   # 苏念线
     longchain.js      # 第 6~15 日长玩法链
     true_end.js       # 真结局路径
     afterword.js      # 后日谈
     index.js          # 汇总成 SCRIPT
   ```
   拆分时务必保持 `SCRIPT` 全局对象结构不变，避免触发回归。

3. **全局命名空间耦合**。`Saves` / `SCRIPT` / `Minigames` / `window.__game` 四个全局对象互相引用，难以单元测试。建议引入一个 `container.js` 做依赖注入，或至少在测试中用 mock 替换。

#### P1

4. **CSS 7985 行单文件**。建议按玩法模块拆分（每个玩法一个 CSS 文件），用 PostCSS 或 Vite 合并。当前 `style.css?v=2.7.7` 的缓存策略依赖手动改版本号，容易出错。

5. **缺少构建工具**。建议引入 Vite：
   - 开发时热重载（当前改一行要手动刷新）
   - 生产时自动压缩 HTML/CSS/JS
   - 自动版本号管理（替代 `?v=2.7.7`）
   - 自动生成 favicon、sprite

6. **测试覆盖不足**。21 项测试主要集中在剧情图可达性和存档边界，缺少：
   - 玩法逻辑的单元测试（如 `d15_chess` 的最短路径算法）
   - 关键词合成的组合测试
   - 时间回溯（`d15_rewind` → `d5_loop_arrival`）的状态一致性测试

#### P2

7. **存档 schema 迁移**。`saves.js` 已有 schema v3，但缺少显式迁移函数表。建议参考 IndexedDB 的 migration 模式，为每个 schema 版本写一个 `migrate_v3_to_v4` 函数，避免未来版本升级时一次性处理过多旧格式。

8. **localStorage 容量风险**。当前存档 + 关键词 + CG + 流程图 + 朋友圈 + 收件箱全在 localStorage（5~10MB 上限）。建议引入 IndexedDB 作为长期存储，localStorage 仅保留最近一次存档用于快速续玩。

9. **可访问性**。`aria-label` 已基本覆盖，但对话框 `role="dialog"` 没有 `aria-live` 焦点管理，屏幕阅读器用户体验仍可改进。建议参考 WAI-ARIA Authoring Practices 的 Dialog 模式补全。

### 4.4 美术 / 音频 / UX 层面

#### P0

1. **立绘为简单 SVG**。当前 5 个角色立绘都是 ~30 行 SVG，辨识度低。建议至少给三女主各做一张正经立绘（可用 AI 生成 + 手工修），或把 SVG 立绘做差异化表情（喜/悲/怒/思）。

2. **BGM / 音效缺失**。`engine.js` 里有 BGM 相关代码但项目里没有音频文件。建议引入：
   - 标题画面：钢琴 + 樱花氛围
   - 共通线：日常轻柔
   - 个人线 GOOD：温暖弦乐
   - 个人线 BAD：钢琴单音
   - 真结局：空灵女声哼唱
   - 后日谈：木吉他
   可用 Suno / Udio 生成 Demo，后续替换为原创。

#### P1

3. **CG 全部为 SVG 字符画**。10 张 CG 都是几十行 SVG，表现力有限。建议优先升级 3 张关键 CG：
   - `cg_letter`（樱花瓣的信，序章核心意象）
   - `cg_true`（樱花信，真结局象征）
   - `cg_festival`（学园祭之夜，真结局舞台）

4. **移动端玩法体验**。响应式 CSS 存在，但拖动类玩法（如 `d10_eclipse` 拖月亮、`d4_fold` 折信）在小屏上手指遮挡严重。建议给所有拖动玩法加「触控偏移」选项（手指上方 30px 显示拖动元素）。

5. **标题画面信息密度**。标题菜单有 10 个按钮（新游戏/继续/读档/结局图鉴/CG/关键词/流程图/真结局/后日谈/关于），新手容易迷茫。建议把「真结局」「樱海后日谈」默认隐藏（已实现 `hidden`），并把「关键词」「流程图」「CG」合并进「图鉴」二级菜单。

#### P2

6. **过场动画**。当前章节切换只有文字，缺少视觉过渡。建议给「第 5 日路线分岔」「第 15 日时间回溯」「樱花祭之夜」三处加 SVG/CSS 过场动画。

7. **多语言**。当前全中文，KEYWORDS / ENDINGS / CHARACTERS 都是硬编码。建议引入 i18n 结构（即使暂不翻译），为未来英文版预留接口。

### 4.5 测试 / 发布层面

1. **Playwright 端到端测试缺失**。`docs/` 多次提到「Browser 已验证」但都是手工回归。建议在 `tests/` 下增加 Playwright 套件，至少覆盖：

   - 三条个人线 GOOD 全通
   - 真结局合成樱花信
   - 后日谈全玩法

2. **版本号管理**。当前 VERSION 文件是 `2.7.7`，每次改动手动改。建议在 `package.json` 同步版本号，并在 CI 中校验 `VERSION` / `index.html?v=` / `package.json` 三处一致。

3. **GitHub Actions**。当前 `.gitignore` 存在但未见 CI 配置。建议加一个 workflow：
   - push 时跑 `npm test` + `npm run test:syntax`
   - tag 时自动发布 GitHub Pages（项目是纯前端，可直接部署）

## 六、重要约束与注意事项

1. **保留的叙事回溯只有两处**：`d5_rewind`（第 5 日钢琴节点触发）和 `d15_rewind`（第 15 日旗阵节点触发）。两处都必须保留 `timeLoop: true` 标记，且文本中必须明确说明回到哪一天。**不能按普通时间线边处理，也不能再增加新的回溯点**（参见 `docs/v2.7.7-story-consistency.md`）。

2. **真结局解锁条件**：三位女主 GOOD 全通 → `true_unbroken`；合成「樱花信」并完成破环 → `true_end`。后日谈入口严格要求 `true_end`，不会被未破环前章提前打开。

3. **第 5 日路线必须由玩家明确选择**，不再按好感度静默抢占（v2.7.7 已修复）。

4. **所有非回溯剧情边的日期和时段必须单调前进**。自动时间图检查会捕获未标记的时间倒退。

5. **后日谈不新增惩罚结局**。所有玩法（时间线排序、回信分拣、留言墙、校刊校对）的正确与错误分支都汇入同一段现实反思，不新增结局编号。

6. **学姐不被召回樱海**。她在新城市生活，明信片只呈现她主动报告的近况。任何新剧情都不能强行让她回校或解释循环机制。

7. **版本号规则**（用户约定）：每次修改加 0.0.1，满十进一。当前 2.7.7，下一次修改应为 2.7.8。

8. **测试通过门槛**：`npm test` 全量通过 + `npm run test:syntax` 通过 + `git diff --check` 通过 + 自动时间图检查无未标记倒退。**修改完必须检查是否成功才能停止**。

9. **存档 schema 当前为 v3**，导入失败时按原始 raw 值回滚。任何新字段必须兼容旧存档或显式迁移。

10. **本项目是开发测试版**，重构无需考虑旧程序兼容性和旧数据，但要先备份旧数据。
