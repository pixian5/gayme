# v3.2.0 · 发布与体验基建（PWA / 分享卡片 / CI 部署 / 证书闭环 / 减动效）

> 时间：2026-10-21 04:10
> 版本：v3.1.3 → v3.2.0
> 范围：「全做」改进清单第一档全部四项 + 减动效。

## 一、PWA 离线化

- `manifest.webmanifest`：standalone、主题色 #241e38、三枚图标（192/512/maskable-512，浏览器实测截图生成）；
- `sw.js`：预缓存全部 25 项静态资源；页面导航**网络优先**（更新及时到达，断网回退缓存），
  其余资源**缓存优先 + 后台更新**（stale-while-revalidate）；
- 缓存版本 `sakura-vX.Y.Z` 由 `tools/bump_version.py` 随版本号**自动同步**——发版即换仓，不会困在旧缓存；
- index.html 注册 SW（仅 https/localhost 安全上下文）；apple-touch-icon + iOS 全套 meta。

## 二、分享卡片

- `assets/og-cover.jpg`（1200×630，60KB）：渐变底 + 标题 + 英文副题 + 副标语 + 花瓣，浏览器截图 + sips 转 JPEG；
- index.html 加 og:title/description/image + twitter:card。

## 三、CI 自动部署自有服务器

- **专用部署密钥** `gayme_deploy_key`（ed25519，仅登录这一台服务器），公钥入服务器 authorized_keys，
  私钥存 GitHub Secrets（`OH_DEPLOY_KEY`）——**不复用万能钥匙**；
- `.github/workflows/deploy-server.yml`：push main → npm test → tar over ssh(:2424) →
  curl 校验线上版本 = VERSION，不一致即红；
- 从此 push 一次 = 三路自动：Pages + 自有服务器 + CI 测试。

## 四、证书续期闭环

- 服务器上 `acme.sh --install-cert -d sbbz.tech --ecc` 注册 `--reloadcmd "nginx -s reload"`：
  续期 → 自动拷贝到 /etc/nginx/ssl → 自动 reload。消除「续期了但 nginx 没换证书」的手动炸弹。

## 五、prefers-reduced-motion

- CSS：系统开启「减弱动态效果」时关闭全部动画/过渡（立绘浮动、按钮过渡等）；
- JS：粒子系统在减动效下不生成。

## 六、验证

- `npm test` 32 / 32 全过；manifest JSON 合法；两个 workflow YAML 校验通过；
- 本地 localhost：SW 注册 → activated，预缓存 `sakura-v3.2.0` 就绪；
- 专用密钥实机登录验证通过；服务器 reloadcmd 实跑成功（Reload successful）；
- 部署后三源版本一致性由 CI 校验（deploy-server.yml 最后一步）。
