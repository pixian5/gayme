# v3.0.0 · 移动端打磨 v1：安全区、触控目标、防误触

> 时间：2026-10-11 09:47
> 版本：v2.9.9 → v3.0.0（满十进一）
> 定位：路线图「移动端打磨」第一版——只动 CSS 与 viewport 声明，零 JS 改动。

## 一、改动

| 项 | 内容 |
|---|---|
| viewport | 加 `viewport-fit=cover`（安全区 env() 生效的前提） |
| 安全区 | 顶栏（top/left/right）、日程条（top/left）、心条（top/right）、对话框（bottom）全部接入 `env(safe-area-inset-*)`——刘海/挖孔屏横竖屏都不再顶边、不压 Home 指示条；桌面 env()=0 无影响 |
| 触控目标 | 顶栏按钮 32→**40px**；选项按钮小屏 86% 宽 + 最小高 48px（拇指可点） |
| 窄屏顶栏 | 12 个按钮一行放不下 → `flex-wrap` 换行右对齐（修复 390px 宽溢出） |
| 防误触 | `#game` 及全部按钮 `touch-action: manipulation`——禁双击缩放，快速点击不误触发放大 |
| 小屏阅读 | 对话框 max-height 46vh + 文本区 30vh 内滚动；浮层面板 94% 宽 / 86vh |

## 二、验证

- `npm test` 32 / 32 全过。
- 浏览器 390×844（iPhone 尺寸）实测截图 ×3：标题屏按钮排布正常；游戏内对话框文本完整、
  底部留出安全区；顶栏按钮 40×40、换行不溢出、无横向滚动；
  `getComputedStyle` 确认 `touch-action: manipulation` 生效。

## 三、后续（移动端 v2 候选）

- 顶栏按钮较多，可考虑小屏收纳进「⋯」折叠菜单；
- 玩法浮层里的拖拽类（风铃/罗盘等）已有 touchstart 适配，个别小目标可再放大；
- 横屏适配（安全区已覆盖，主要是布局密度）。
