# v3.3.12 设置扩展：减少动效与界面字号（DeepSeek）

日期：2026-10-24 10:35 · 模型：DeepSeek · 版本：v3.3.12

## 背景

按《下一步开发完整计划》Phase 1 继续，本轮实现 **P1-3 设置扩展**。

## 改动

| 项 | 说明 |
|---|---|
| 新设置项 | `DEFAULT_SETTINGS` 新增 `fontScale: 1`、`reduceMotion: false`；`fontScale` 纳入 `NUMERIC_SETTING_RANGES`（0.9–1.3），`reduceMotion` 纳入布尔归一化白名单 |
| 设置面板 | 新增「减少动效」开关、「界面字号」滑杆（0.9–1.3，实时百分比） |
| 减少动效 | 开启时：`document.body` 加 `.reduce-motion`（CSS 关闭动画/过渡），粒子系统直接停用；与系统 `prefers-reduced-motion` **叠加**生效 |
| 界面字号 | 通过 CSS 变量 `--ui-scale` 应用到 `#dialog-text`（桌面 21px / 移动 17px 均 `× var(--ui-scale)`），改滑杆即时生效 |
| 应用时机 | 新增 `applyUiSettings()`，在 `init()` 与设置变更时调用 |

设计取舍：字号只作用于对白文本（信息密度最高处），不改全局布局，避免 `zoom` 类方案造成的
排版错乱；减少动效采用「动画/过渡时长归零 + 停粒子」，不隐藏内容。
