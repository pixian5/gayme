# v3.3.11 CG 大图查看器（DeepSeek）

日期：2026-10-24 10:12 · 模型：DeepSeek · 版本：v3.3.11

## 背景

按《下一步开发完整计划》Phase 1 继续，本轮实现 **P1-2 图鉴增强（CG 大图）**。

## 改动

| 项 | 说明 |
|---|---|
| 入口 | CG 图鉴中**已解锁**卡片可点击（`data-cg`，鼠标指针变化） |
| 查看器 | 新增 `.cg-viewer-layer` 浮层：放大显示 CG（SVG 自适应宽度）、标题 +  heroine + 序号（i/N） |
| 操作 | 「上一张 / 下一张」按钮、**←/→** 方向键切换（循环）、**Esc** 或点击空白关闭 |
| 一致 | 浮层 class 以 `-layer` 结尾 → 自动纳入 `hasActiveInteractionLayer` 交互锁与 `backToTitle` 清理 |
| 样式 | `.cg-viewer-layer / .cg-viewer-*`（暗色玻璃背景、居中、圆角阴影） |

未解锁 CG 不可点击（保持锁态占位）。

## 经验

- **浮层统一走 `.xxx-layer` 命名**：交互锁、返回标题清理、按键防误触都依赖「class 以 `-layer` 结尾」
  这一约定；新浮层沿用即免费获得这些能力，无需改引擎核心。
- **查看器键盘处理要挂号在浮层自身**：全局 keydown 遇交互层会早退，故把 Esc/方向键挂在浮层
  元素 `onkeydown` 上并 `stopPropagation`。
