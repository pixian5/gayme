## 一、BGM 重写（三层结构 + 精确调度）

旧实现：单振荡器、每 tick 随机播一个音阶音符（听感为无结构滴答）。

新实现（保持 `ensureAudio` / `playBgmForScene` / `stopBgm` 对外接口不变）：

| 层 | 内容 | 音色 |
|---|---|---|
| 和弦垫 | 4 小节循环进行（各 mood 独立配置，如 sad 用 Am-F-G-E），每小节慢起慢落铺满 | triangle |
| 低音 | 每半小节一个根音（低八度），短包络 | sine |
| 旋律 | 五声音阶**随机游走**（80% 级进 / 20% 跳进，30% 概率长音），密度随 mood（calm 0.32 ~ active 0.7） | sine/triangle |

- **look-ahead 调度器**：150ms 间隔、0.5s 前瞻，按 `AudioContext.currentTime` 精确排程，
  替代旧的 setTimeout 逐音排程——节奏不再漂移；
- 五个 mood（default / bright / sad / calm / active）各有 bpm、和弦进行、音阶、密度与三层音量配比；
  场景映射沿用原表（ending_good→bright、rain→sad、library→calm 等）。

## 二、程序化音效（5 种）

`playSfx(kind)`：sine 短包络序列，经独立 `sfxGain`（受设置面板新增的「音效音量」滑杆控制，
0.6 默认——该设置项 saves.js 早已预留默认值与范围校验，本版补上 UI）：

| kind | 触发点 | 听感 |
|---|---|---|
| letter | showLetter 信件节点 | 两音上行铃 |
| keyword | 剧情解锁关键词 | 双音提示 |
| memory | 剧情记忆 / GameKit 记忆 / 合成回忆三处 | 三音闪烁 |
| success | GameKit finish 结果 tag === "perfect" | 四音上行琶音 |
| fail | GameKit finish 结果 tag === "miss" | 两音下行 |

音效桥接：`window.GameSfx.play(kind)`，gamekit.js 与引擎均可调用；`sfx === false` 或无手势时静默。
