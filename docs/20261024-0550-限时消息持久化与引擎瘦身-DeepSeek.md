## 四、经验

1. **限时机制要落盘「起点时间」而非「剩余量」**：只存剩余或不持久化，会让反复开关重置计时。
   正确做法是持久化首次开始时间戳，用 `deadline - (now - start)` 推算，天然防重置、防作弊。
2. **浮层无障碍要配焦点陷阱**：`aria-modal="true"` 只是语义，实际 Tab 仍会跑到背景；
   需要在浮层内拦截 Tab / Shift+Tab 做循环。
3. **快进连跳要设「安全边界」**：自动推进必须排除一切有互动或有副作用的节点，
   并以「已读」为闸门，否则会跳过未读剧情或互动。
4. **迁移后要清理宿主侧的重复文档**：玩法迁到 `js/games/*.js` 时连带细化了 schema 注释，
   宿主 engine.js 里的旧副本成了重复死重；迁移类重构收尾要检查源文件残留。
5. **审计结论也可能误判**：`stopBgm→setScene` 曾被记为 bug，实为标题曲播发设计；
   动手前先确认「意图」，避免把正常设计改坏。
