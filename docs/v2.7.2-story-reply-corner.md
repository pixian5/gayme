# v2.7.2 半年后回信角剧情记录

## 本轮内容

- 时间线玩法完成后进入半年后的秋天，新增“回信角”支线。
- 玩家为一张公开纸条自由写回信，按“先留下、先迈一步、先倾听”或无法归类的内容进入四种回应。
- 新增回信角规则选择：署名日期、先问需要、允许空白；所有规则都回到原有“樱海以后”结局。
- 流程图和剧情图测试覆盖新增节点、自由书写分支与规则分支。

## 内容合理性检查

- 时间跨度明确为半年，避免把时间线的一周后直接误写成下一天。
- 回信角是署名、写日期的校内公告栏，公开沟通与三年前的匿名信分开，不重新制造超自然循环。
- 来信者只问“能否先留下”，玩家不替对方决定学校、职业或人生终点；回应只落到当下可执行的一步。
- 三位角色的回应符合既有成长：诗雨降低控制感，夏织把冲劲缩成一小步，苏念给不确定性留出空白。
- 规则分支体现不同的关怀边界，没有把好意写成义务，也没有强迫学姐回到樱海。
