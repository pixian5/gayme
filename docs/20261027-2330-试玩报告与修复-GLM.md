## 二、试玩发现并已修复（v3.4.17）

### BUG-1：快通条从不显示（快进+已读玩法）★★★
- **现象**：二周目快进中进入已读玩法，说明栏出现、跳过按钮出现，但「⟲ 已读·快通中」条永不出现——已读快通从未生效过；
- **根因**：v3.4.16 修说明栏时发现「玩法 handler 在 createShell 后 `layer.innerHTML = ...` 会覆盖 layer 内节点」，把说明栏挪到了 #game——**但同批的快通条（v3.4.13）还挂在 layer 里**，同样的坑漏改了；手造 shell 验证 innerHTML 前有条、innerHTML 后消失，实锤；
- **修复**：快通条与说明栏同策略，挂 #game 兄弟节点。

### BUG-2：direct.js 10 个玩法快通与跳过收尾失效 ★★
- **现象**：doodle/collage/photo/rhythm/scent/silenceChoice/touch/temperature/handwriting/spectrum 的 `createShell({ kind })` 漏传 `nodeId`；
- **影响**：`isFastReplay(undefined)` 恒 false（快通失效）+ `jumpNext(undefined)`（跳过按钮会停在原地）；
- **修复**：10 处调用补 `nodeId`。

### 发现-3（v3.4.18 已修）：同节点重复 gotoNode 会叠浮层
连续对同一节点 gotoNode 会创建多个 layer（引擎 gotoNode 无同节点防重入）。
真实玩家操作触不到（正常推进不会重复进入同节点），但已修：gotoNode 开头防重入
（游戏内 + 非读档 + 同节点 → return；读档 restoring 例外保留——重放同节点是读档的合法路径）。
首版条件引用了不存在的 `el.game` 从未生效，改为直接判 `state.inGame && state.currentNode === nodeId`。
实机验证：连按 3 次同节点浮层 1 个 ✓；restoring 重放正常 ✓。

## 三、体验确认（好的部分）

1. **新手引导**：首次进入清晰列出推进/选择/快捷键，点「开始故事」进入顺畅；
2. **说明栏三行**：星座/梦境/塔罗/涂鸦实测内容准确可懂——「按顺序点击星点连线」「跟着第一直觉点，牌不会错」「画得越放得开，读出来的情绪越清楚」，从「不知道干嘛」到「知道干嘛」的直接原因；
3. **跳过按钮**：塔罗直接跳过 → 干净落到下一节点，零残留；
4. **loopText**：二周目序章首句即「——又是四月。樱花照旧开……」，既视感立现；
5. **快进连跳**：已读纯文本节点自动推进（打字瞬间完成），卡点只在视角节点（有意设计：点一下继续——见发现-4）；
6. **结局画面**：《挣》GOOD 画面/标题/类型显示正确，返回标题后 loopCount+1。

### 发现-4（体验观察，建议讨论）
- 视角节点（perspective）会停住快进且无提示——玩家不知道「点一下继续」。低频（全剧本视角节点不多），可在后续版本给视角按钮加 1s 脉冲动画提示；
- 星座玩法说明没提到最后要点「解读星图」按钮（说明写的是连线，实际连完还要点确认类按钮）——v3.4.16 的 89 条说明里这类「最后一步」信息有几处遗漏，可在反馈中逐条补。
