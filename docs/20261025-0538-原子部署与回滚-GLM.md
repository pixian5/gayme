# v3.3.21 · 服务器原子部署 + 一键回滚（P0-4）——已实跑验证

> 2026-10-25 · GLM

## 问题

cron 部署脚本（v1）只会 rsync 覆盖 `/var/www/sakura`：无预检、无回滚——坏版本上线后只能等下次 push 修复。

## 方案（服务器侧，已安装并于本次 push 实跑验证）

| 组件 | 说明 |
|---|---|
| 发布目录 | `/var/www/releases/<sha>/`（保留最近 3 个） |
| nginx 根 | `/var/www/sakura` → **symlink** 指向当前版本（`ln -sfn` 原子切换） |
| 上一版 | `/var/www/sakura.prev` → symlink，部署时自动记录 |
| 部署流程 | 拉取（gitee 主/github 备，沿用 v1）→ rsync 到 `.staging` → **预检**（index.html 含 VERSION 串，失败保持旧版）→ 原子切换 → 健康检查（curl 版本串），**失败自动回滚**并记日志 |
| 回滚 | `sudo /usr/local/bin/sakura-rollback.sh`（prev/cur 互换，可来回切换） |
| 兼容 | 老实体目录首次运行自动迁移为 releases 布局；旧脚本备份 `sakura-deploy.sh.v1.bak` |
