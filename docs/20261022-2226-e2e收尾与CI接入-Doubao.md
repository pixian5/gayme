# v3.2.1 · e2e 收尾与 CI 接入（问题根因与修复记录）

> 时间：2026-10-22 22:26
> 版本：v3.2.0 → v3.2.1
> 模型：Doubao

## 背景

v3.2.0 遗留：工作区有未提交的 e2e 测试雏形（package.json 已改未提交、
package-lock.json 与 tests/browser/ 未跟踪），且 e2e 实测 10 分钟无法完成、疑似卡死。
本轮定位根因并收尾。

## 根因（4 个 bug，均在本轮修复）

### 1. ROOT 路径错误（致命）

`tests/browser/engine.e2e.mjs` 原写法：

```js
const ROOT = join(fileURLToPath(import.meta.url), "../..");
```

`path.join` 不区分文件与目录：`join("/…/tests/browser/engine.e2e.mjs", "../..")`
把文件名当作路径段参与归一化，得到 `/…/tests`（应为项目根 `/…`）。
结果静态服务器对 `/js/saves.js` 等全部 404，页面只加载出 HTML 空壳。

**修复**：先 `dirname(fileURLToPath(import.meta.url))` 取目录再 `../..`：

```js
const ROOT = join(dirname(fileURLToPath(import.meta.url)), "../..");
```

### 2. 测试失败后进程挂着不退出

断言失败抛错后，`browser.close()` / `server.close()` 在测试体末尾不执行，
静态服务器保持监听，node 进程永不退出——这就是「10 分钟跑不完」的真相：
测试其实早已失败，只是进程没退出。

**修复**：加 `test.after` 统一兜底清理（无论成败都关浏览器与服务器）。

### 3. `window.Saves` 永远 undefined

`saves.js` 以顶层 `const Saves = {…}` 声明（script.js 的 `SCRIPT` 同理）。
顶层 const 创建**全局词法绑定**，但不挂到 `window` 属性上，
所以 `page.waitForFunction(() => window.Saves && window.__game)` 恒为 false 而超时。

**修复**：改用 `typeof Saves !== "undefined" && window.__game`。

### 4. `window.closeOverlay` 不存在

`closeOverlay` 是 engine.js 内部函数，`window.__game` 导出只有
`{ state, gotoNode, newGame, backToTitle, openOverlay }`——open 有 close 无，不对称。

**修复**：engine.js 的 `__game` 导出补上 `closeOverlay`（产品代码一行，API 对称），
e2e 改用 `window.__game.closeOverlay()`。

## 其他改进

- `test.before` 探活 launch 后立即 `close()`，不再泄漏浏览器实例。
- 六步测试各加 `console.log("[e2e] n/6 …")` 进度日志，失败可定位到具体步骤。
- 等待页面初始化加 15 秒超时；整体测试超时 120 秒。

## 结果

- 本机 `npm run test:e2e`：**2.7 秒全过**（修复前 10 分钟无法完成）。
- `npm test` 32/32 全过；`test:syntax` 全过。
- 新增 `.github/workflows/e2e.yml`：push main / PR 时 ubuntu runner
  `npx playwright install --with-deps chromium` 后跑 e2e，配 actions/cache 缓存浏览器加速。
- `tools/bump_version.py 3.2.1` 同步 VERSION / package.json / index.html / sw.js 缓存版本。

## 经验沉淀

- `path.join` 拼接文件路径的 `../` 前**必须先取 dirname**，否则目录算错（此类 bug 无报错，
  表现是「页面静默 404」）。
- node:test 失败后要确保 server/browser 关闭，否则进程挂着，CI 会超时误判。
- 顶层 const 不挂 window，跨脚本可用但 `window.X` 取不到——测试判断用 `typeof`。
- 测试暴露的 API 缺口（closeOverlay）优先补到产品侧对称导出，别在测试里绕 DOM。
