# v3.3.19 · SW 三层缓存：首装下载 11MB → 1.3MB

> 2026-10-25 · GLM（Phase 3 P0-2）

## 改动（sw.js）

| 层 | 内容 | 策略 |
|---|---|---|
| 核心层 `sakura-vX.Y.Z` | html/css/js/字体/图标/manifest（install 预装） | 版本换仓，activate 只清 `sakura-v*` 旧仓 |
| 媒体层 `sakura-media` | audio/*.ogg、assets/cg/*（运行时首次请求写入） | **跨版本沿用**，不清空；cache-first + 后台更新 |
| 网络 | 其余同源 GET | 沿用原 stale-while-revalidate |

- 页面导航保持网络优先（更新及时到达）；
- 效果：首装下载 11MB → ≈1.3MB；已听过的 BGM / 已看过的 CG 离线可用；发版不再重下媒体。

## 验证

- `npm test` 42/42；e2e 7/7（chromium 6.9s）；
- bump 工具自动同步 CACHE_VERSION（媒体层不随版本变，天然跨版本沿用）。
