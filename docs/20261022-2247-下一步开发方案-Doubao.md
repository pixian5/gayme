## 二、路线（按优先级）

### P0 · 修复

**P0-1 字体子集重建**（S，阻塞=WiFi）
- `bash tools/rebuild_font_subset.sh`（下载约 23MB 源字体），重建后 `check_font_coverage.py` 确认 0 缺失。
- 当前无流量，先排队；可先跑 `collect_font_charset.py` 把最新字符集清单刷好待用。

**P0-2 非 Mac 平台 UI 符号兜底**（S，无阻塞）
- 界面高频符号（⋯⏩⏱⏳■□△▽◆◇⟲）在 Noto 子集外会豆腐块，仅影响 Windows/Android/部分 Linux。
- 方案：符号位换用 emoji/ASCII 变体，或待 P0-1 一并解决。二选一由用户定。

### P1 · 内容纵深（主线）

**P1-1 多周目文本差异化**（M，无外部依赖，可立即开工）
- 现状：loopText 机制已就绪但全剧本仅 1 处使用，二周目文本与一周目几乎完全一致，重玩动力低。
- 改动：选 30~50 个关键节点补第二/三周目变化文本——
  - 共通线高频节点：主角既视感独白（"这句话，我说过"类）
  - 三女主关键节点：微变台词（暗示对方有隐约熟悉感）
  - 选项节点：选择回响（上周目选择在对话中闪现）
- 验收：loopText 覆盖 ≥30 节点；时间线单调约束不破坏；`npm test` + e2e 全过；二周目实跑抽样验证。

**P1-2 合成回忆扩展**（S）
- 现有 6 段合成回忆 → 扩到 10~12 段（补充关键词组合），进记忆图鉴。
- 验收：新组合可解锁；图鉴展示正常。

**P1-3 学姐线补完**（L，需用户拍板）
- 学姐"信之影子"设定已自洽（v3.0.1），但角色停在引导位，无专属结局。
