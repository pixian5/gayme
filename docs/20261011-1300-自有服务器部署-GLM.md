## 二、发布流程（每次发版）

```bash
# 1) 正常发版：改代码 → bump_version → 测试 → commit → push 双远程
# 2) 同步自有服务器（一条命令）：
bash tools/deploy.sh
```

`tools/deploy.sh`：tar 打包站点文件 → ssh(:2424) 管道直传解包到 `/var/www/sakura` →
自动 curl 校验线上版本号与本地 VERSION 一致，不一致退出非零。
支持环境变量覆盖：`DEPLOY_HOST / DEPLOY_PORT / DEPLOY_USER / DEPLOY_KEY`（换服务器时零改代码）。

## 三、注意事项

- 2424 是该机 **SSH 端口**（与 22 双端口并存），Web 走 8080，两者不冲突；
- 8080 依赖 AWS 安全组放行（实测可达）；换机器时需确认新安全组放行 8080；
- 证书到期 2026-12-11 前后由机内 acme.sh cron 自动续期（续期后 acme.sh 的 reloadcmd
  不涉及 nginx——若续期后报证书过期，重跑一次服务器侧的 cp + reload 即可，已记入本文件）；
- Pages 与自有服务器为**平行双源**，内容同版本；deploy.sh 会校验两端版本一致。
