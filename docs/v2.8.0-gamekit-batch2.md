按 v2.7.9 建立的路线继续迁移：把 v1.0.0 / v1.1.0 批次的 8 个身心感知玩法迁出 engine.js，

## GameKit 扩展（因真实需求而加，非预设）

| 能力 | 说明 |
|---|---|
| `prefix` | 结果面板类名前缀可与浮层不同（这批玩法历史上用 br / tc / fd / rf / ld / mm / sn / pl 等缩写） |
| `memory` | 收尾时统一处理记忆解锁与提示（`✦ 新记忆：…`），8 个玩法全部依赖 |
| `onCancel` | 取消钩子：读档 / 返回标题时执行 rAF 取消、ResizeObserver 断开等清理 |
| `signal` | 暴露 GameLifecycle 的 AbortSignal，玩法的事件监听随之自动解绑 |
| `flashHint` | 宿主顶部提示（记忆解锁、脉搏命中 ✓/✗ 反馈） |
| `cleanup()` 幂等 | 收尾与取消共用同一条清理路径，重复调用安全 |

## 顺带完成的工程项

1. **替换掉 4 处自建清理机制**：breath / reflection / lightdraw / pulse 原先各自用 `MutationObserver` 监听浮层移除来清理
   rAF、document 监听与 ResizeObserver；现在统一由 GameLifecycle + AbortSignal + onCancel 承担，行为等价且不再依赖 DOM 观察。
2. **死代码清理**：删除 `el.quickAccess`（引用了不存在的 `#quick-access`，且零使用）。
3. **新增 tests/consistency.test.mjs**：
   - 版本号在 VERSION / index.html（全部 `?v=`）/ package.json 三处一致，且标题页版本同步；
   - `js/` 与 `js/games/` 下所有脚本都必须在 index.html 中加载，且 `engine.js` 最后加载。
