# v3.4.53 · 可选账号与云存档（Doubao）

## 结论

GAYME 从「纯静态、无账号」升级为「本地默认 + 可选账号」：

- 不启动账号服务、不登录时，游戏仍然纯本地、离线可玩，原有 localStorage 存档、图鉴、设置、SW 离线缓存全部不变。
- 启动同源 Node 账号服务后，设置页出现账号面板，支持注册、登录、一次性找回码、改密、改昵称、设备管理、导出账号数据、注销账号。
- 云存档按**整包 JSON** 上传，不逐槽位迁移；用 `revision` + `baseRevision` 做乐观锁，冲突返回 409，由玩家选择云端覆盖本机或本机覆盖云端，不做静默覆盖。
- 线上已部署在 InstaBox 盒子 `xjp`（对外 URL 仍是 `https://8090-agqxoy6u363jxgfufg2onqxbm4.instabox.tech/`），`/api/health` 返回 `3.4.53`，注册/登录/上传/刷新保持均已实测。

## 架构

```
浏览器（游戏静态页 + js/account.js）
   │  同源 fetch /api/*（credentials: include，X-Requested-With: gayme-account）
   ▼
nginx:alpine 容器 sakura-web（8090）/ sakura-tls（2096）
   │  location /api/ → 172.17.0.1:8096
   ▼
Node 账号服务容器 sakura-account（node:24-bookworm-slim）
   │  node:sqlite（WAL）
   ▼
/data/home/gayme-account/data/game.db
```

- 静态站点根：`/data/home/sakura`（nginx 只读挂载）。
- 账号代码：`/data/home/gayme-account/app/server`（非公开目录，站点根绝不放 `server/`）。
- 数据库/日志/备份：`/data/home/gayme-account/data`。
- 账号容器与站点容器共用 Docker 默认 bridge；nginx 通过宿主机网关 `172.17.0.1:8096` 反代。容器发布端口只绑定 `172.17.0.1`，不直接暴露公网。

## 后端

| 文件 | 职责 |
| --- | --- |
| `server/config.mjs` | 端口/主机/DB、会话 30 天、单账号最多 10 会话、JSON 8MB、云存档 6MB、审计 90 天、反向代理与 Cookie Secure 配置 |
| `server/auth.mjs` | scrypt（N=16384,r=8,p=1）、随机 token、SHA-256 token 哈希、找回码 `ABCD-EFGH-IJKL`、Cookie `gayme_session`、IP、固定窗口限流、5 次失败锁 15 分钟 |
| `server/db.mjs` | SQLite 表 `users` / `sessions` / `saves` / `audit_log`，WAL、外键级联、用户名 `COLLATE NOCASE`；`deleteAllSessions` |
| `server/api.mjs` | 全部 `/api` 路由与校验；非 GET 必须 `X-Requested-With: gayme-account`；有 Origin 时校验同源；云存档 revision 冲突 409 |
| `server/index.mjs` | 同进程静态站 + API；静态白名单（含 `sw.js`）；拒绝 `server/` `docs/` `tests/` 等；安全头、日志、优雅退出 |
| `server/ctl.sh` | 本地/服务器 start/stop/restart/status/logs/backup |
| `server/backup_db.mjs` | `VACUUM INTO` 在线备份，保留最近 30 份 |

### 数据表

- `users`：id、username、nickname、pwd_hash、pwd_salt、recovery_hash、recovery_salt、created_at、updated_at。
- `sessions`：id、user_id、token_hash、created_at、last_seen_at、expires_at、ua、ip。
- `saves`：user_id 主键、data（整包 JSON）、revision、bytes、sha256、schema_version、exported_at、updated_at。
- `audit_log`：user_id、action、detail、ip、created_at；90 天清理。

### 安全边界

- 密码/找回码只存 scrypt 加盐哈希；会话只存 token 哈希；`ctx.user` 携带哈希材料仅供服务端校验，`userPublic()` 不输出。
- 注册 5 次/小时/IP；找回 10 次/15 分钟/IP；账号操作 30 次/15 分钟/IP；密码 8-72 位且字母+数字；用户名 3-20 位字母数字下划线且不能纯数字。
- 非 GET 的 JSON 请求体上限 8MB；云存档 6MB；超限 413 且服务存活。
- Cookie：HttpOnly、SameSite=Lax、30 天；HTTPS 下 Secure。

- `js/account.js`：设置页账号面板；登录/注册/找回码/账号/冲突视图；一次性找回码；设备列表；导出；注销；自动同步。
- `js/ui/panels.js`：设置页 `#cfg-account` 容器，`renderConfig` 末尾 `AccountUI.mount()`；修复 `cfg-export` 的 `backup` 未定义；关于页 Gitee issues 死链替换为邮件反馈。
- `js/saves.js`：`SAVE_EVENT_KEYS`、`sakura:saved` 事件、`_importing` 防导入半成品广播。

### 同步状态机

- 本地键：同步锚点 `gayme_cloud_meta:<username>`；自动同步开关 `gayme_account_autosync`。
- 上传前删除 `currentSession`、`incompleteKeys`，避免把当前设备的瞬时会话写进云端。
- 登录时若云端 revision 高于本地锚点且本机有存档，进入冲突暂停；自动同步不覆盖。
- 云恢复调用 `Saves.importData`，由其触发引擎 `backToTitle` 与 `flashHint`；导入期间 `_importing` 阻止广播。
- 自动同步在 `sakura:saved` 后 5 秒防抖上传；冲突后暂停，直到玩家处理或重开自动同步。

## 踩坑记录

1. **注册后找回码被启动 `/me` 覆盖**：`boot()` 在 `mount` 时发 `/api/health` + `/api/auth/me`，若用户在返回前完成注册，旧 `me=null` 结果会 render 登录页。修法：boot 记录 `authRevAtBoot`，认证代号变化就丢弃启动结果。
2. **注册后直接显示账号页，找不到「我已保存」**：`render()` 原本 `state.me ? renderAccount() : renderGuest()`，注册已设置 `me`，导致一次性找回码只出现在账号页底部。修法：`state.view === "registered"` 时强制 `renderGuest()`，先展示找回码页，确认后进账号。
3. **改密 401**：`authenticate` 的 `ctx.user` 没带 `pwd_hash/pwd_salt`，`scryptVerify` 拿不到材料。修法：`sessionByHash` 查询补选四个哈希字段，`ctx.user` 携带但 `userPublic` 不输出。
4. **找回 500**：recover 路由用 `store.raw.exec("DELETE ... " + JSON.stringify(id))` 触发 SQLite 双引号错误。修法：`store.deleteAllSessions(user.id)` 预编译语句。
5. **公网注册 csrf_blocked**：InstaBox 前置代理把 Host 改成 `127.0.0.1`，nginx 又用 `$scheme` 覆盖 `X-Forwarded-Proto`；浏览器 Origin 是 `https://8090-...instabox.tech`，服务端 expected 变成 `https://127.0.0.1`。修法：nginx 透传 `X-Forwarded-Host $http_x_forwarded_host` 与 `X-Forwarded-Proto $http_x_forwarded_proto`，服务端优先读 XFH。
6. **账号脚本 403**：Write 创建的文件权限 600，nginx worker 读不到。修法：部署后 `chmod -R a+rX`。
7. **SW 注册 404**：账号服务的静态白名单漏了根 `sw.js`，浏览器报 “bad HTTP response code 404 when fetching the script”。修法：`PUBLIC_FILES` 加 `sw.js`。
8. **站点根差点暴露 `server/`**：cron rsync 原先只排除 docs/tests/tools，新增 `server/` 必须排除；账号代码单独放非公开目录。
9. **Node 内置 SQLite 实验警告**：Node 24 仍打印 ExperimentalWarning，不影响运行；容器固定 `node:24-bookworm-slim`。
