## 三、顺手修复

- **stethoscope 定时器竞态修复**：原实现无清理钩子——读档 / 返回标题后，残留的
  rAF 绘制循环与 `setTimeout(finishStethoscope)` 会照常触发，进而写入记录、应用好感加成
  （原 bug）。迁移时经 `createShell({ onCancel })` 置 `finished = true` 并取消 rAF、
  移除 keydown 监听，后续定时器触发会被 `if (finished) return;` 守卫拦下。
