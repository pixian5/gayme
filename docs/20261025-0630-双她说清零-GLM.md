# v3.3.26 · 双「她说」句式清零（S-1）

> 2026-10-25 · GLM · 剧情文本 44 处全部改写

## 问题

第 5~15 日长链的玩法节点文案是同一三段式模板：
「她——【道具】。她说——【指令】。她说：【格言】」——34 个节点一段话里出现两次以上
「她说」，叠加玩法同质化，形成强烈阅读疲劳。

## 改写原则

1. **保留内核**：道具、操作指令、格言三要素一个不少（含 loopText 契约与文本一致性测试锚点）；
2. **句式多样化**：第二句改为动作转述（比划手势/递东西/蹲下/转身）/载体转移（写在灰上、
   盒盖内侧、琴身）/说给谁听（说给水面、说给碑、迎着风喊）；
3. **每篇至多一次「她说」**——保留的那次承担情绪重点；
4. **失败安慰文案引语化**（10 处）：「她说：X」→「"X。" 你想她说的是对的」——
   直接引语前置，把「你想她说的是对的」留在句尾做追认，节奏更真实。
