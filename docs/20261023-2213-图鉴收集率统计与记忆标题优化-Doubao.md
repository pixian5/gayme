## 一、改动清单

### 1. 图鉴收集率统计（体验优化）

- **结局图鉴**（renderGallery）：顶部新增进度条「✦ 结局收集 x/13」+ 渐变进度条
- **CG 图鉴**（renderCGGallery）：顶部新增「✦ CG 收集 x/11」进度
- **关键词面板**（renderKeywords）：顶部新增「✦ 收集进度：关键词 x/11 · 合成 x/11 · 记忆 N 段」
  （合成进度含 COMPOSE_RECIPES 总量）
- 意义：玩家一眼看到收集缺口，驱动多周目探索（隐藏结局/学姐线/CG/关键词）

### 2. 记忆卡片标题优化

- **既有问题**：`Saves.saveMemory(id, text)` 只存 id+text，图鉴记忆卡片标题显示内部 id
  （如"序章·诗雨"），而数据里本有更友好的 `title`（如"走廊相遇"）
- **修复**：saveMemory 增加可选 `title` 参数；engine.js 5 处有 memory 对象的调用点传入 title；
  渲染优先 `m.title || m.id`（旧存档无 title 自动回退 id，兼容不破坏）
- 影响面：新解锁记忆显示友好标题；旧存档显示不变

### 3. e2e 补收集进度断言

- 学姐线第 7 项扩展：结局图鉴断言「x/13」进度文本、CG 图鉴断言「x/11」、关键词面板断言「收集进度」
- 7/7 仍全绿
