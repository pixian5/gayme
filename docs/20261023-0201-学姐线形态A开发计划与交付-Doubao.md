## 一、目标

为「信的真正主人」学姐补一条可攻略支线，新增第 13 个图鉴结局（第 12 个剧情结局）。这条线独立存在，不改变现有真结局判定、后日谈解锁条件和三女主 GOOD 门槛。

完成标准：

1. 二周目（已解锁 `true_unbroken` 且 `loopCount ≥ 1`）在第 5 日路线选择出现隐藏入口；
2. 学姐线有完整的 3 章剧情、3 个选择点、1 次自由写信、1 个专属结局；
3. 结局进入结局图鉴，不触发 `true_end`、不解锁后日谈；
4. 全量测试（`npm test` / `test:syntax` / `test:e2e`）通过，浏览器实跑通关；
5. 版本、文档、字体子集、PWA 缓存同步，推送双远程并线上校验。

## 二、核心设定决策

### 2.1 落点：留在循环里，但被看见

`true_3` 已明确写下设定：

> 「信在，影子就在；等有人把信写完，我才能真的走。」

因此支线**不能**让学姐直接离开，否则会拆掉真结局的前提。最终落点定为：

- 循环没有破，学姐仍然是信留下的影子；
- 但主角选择留在这一轮，陪她把没做完的事做完，并给她写了一封**不是钥匙、只是写给她的信**；
- 她第一次被当作一个具体的人看见，而不是一个等待被解救的影子。

这不是「拯救」，是「看见」。与三女主线的主题（不替她们走完，只在卡住时递一句话）保持一致。

### 2.2 入口：第 5 日隐藏第 4 选项

- 位置：`d5_route_check`（「这个周末，去见谁？」）
- 选项：`⟲ 去旧校舍找学姐`
- 条件：`loopCount ≥ 1` **且** 已解锁 `true_unbroken`
- 原因：`true_unbroken` 是玩家已经听完学姐自白、但没合成「樱花信」的结局；此时进入学姐线不会剧透，也符合「又一个春天」的循环语义。
- 基础 3 个选项保持不变，`d5_route_check.choice.options.length === 3` 的既有测试继续成立。

### 2.3 结局

| 字段 | 值 |
|---|---|
| id | `senior_shadow` |
| heroine | 学姐 |
| title | 看 见 |
| type | `SIDE`（结局画面显示 `SIDE ENDING`） |
| desc | 循环没有破，她也没有走；但这一次，她不再是没人看见的影子。 |

### 2.4 不可破坏边界

1. 不新增循环机制解释，只引用 `true_3` 已公开的信息；
2. 学姐不被召回樱海、不离开循环；
3. 不影响 `true_end` / `true_unbroken` 的判定与文案；
4. 不解锁后日谈（后日谈仍只由 `true_end` 解锁）；
5. 不改变三女主 GOOD 门槛与标题页「真结局」按钮逻辑；
6. 不新增关键词（避免合成配方覆盖测试扩散），只新增记忆片段。

## 四、代码改动清单

### 4.1 `js/engine.js`

1. 选项过滤新增 `requires_ending`：
   - `showChoices()` 与 `showLetter()` 的经典选项分支各加一行：
     `if (opt.requires_ending && !Saves.isEndingUnlocked(opt.requires_ending)) return;`
2. 流程图新增分组「学姐线」，节点：`route_senior_1`、`senior_3`、`senior_6`、`senior_10`、`senior_11`、`senior_12`、`senior_14`、`senior_ending`。
3. 关于页结局数文案同步：`3 位女主 + 学姐线 · 12 个结局 + 1 篇后日谈`。
4. 头注释新增 v3.3.0 变更说明。

### 4.2 `js/script.js`

1. `d5_route_check.choice` 新增 `loopChoice`：
   `{ minLoop: 1, text: "⟲ 去旧校舍找学姐", next: "route_senior_1", requires_ending: "true_unbroken" }`
2. 新增学姐线 24 个节点（放在真结局章节之后、后日谈之前，单独注释分区）。
3. `ENDINGS` 新增 `senior_shadow`（放在苏念 BAD 之后、`true_unbroken` 之前）。
4. `CGS` 新增 `cg_senior_shadow`（SVG 字符画，复用现有色调；不新增位图资源）。
5. 新增记忆片段 6 个（2 个节点记忆 + 4 个回信记忆），全部通过现有 `saveMemory` 落盘。

### 4.3 测试

`tests/story-graph.test.mjs` 新增：

- 学姐线入口元数据：`minLoop=1`、`requires_ending="true_unbroken"`、`next="route_senior_1"`；
- 学姐线全节点从 `d5_route_check` 可达；
- 时间单调（第 5 → 11 日，不出现倒退）；
- `senior_ending.ending.id === "senior_shadow"` 且已在 `ENDINGS` 注册；
- `ENDINGS` 长度为 13，`senior_shadow` 不影响 `isTrueEndUnlocked()`；
- 引擎存在 `requires_ending` 过滤。

`tests/browser/engine.e2e.mjs` 新增第 7 阶段：

1. 写入 `true_unbroken` + `loopCount=0` → 第 5 日只有 3 个选项（条件未满足，隐藏项不出现）；
2. 写入 `loopCount=1` → 第 5 日出现 4 个选项，隐藏项文案正确；
3. 点击隐藏项 → 进入 `route_senior_1`；
4. 直达 `senior_ending` → 结局画面显示、`senior_shadow` 入图鉴、图鉴 13 张、后日谈按钮仍隐藏；
5. 全程控制台零错误。

### 4.4 字体

## 六、风险与回滚

| 风险 | 处理 |
|---|---|
| 学姐线让角色离开，破坏真结局前提 | 落点固定为「留在循环、被看见」；结局文案显式说明循环未破 |
| 新增入口影响原有 3 选项测试 | 只加 `loopChoice`，基础 `options` 仍为 3 |
| `requires_ending` 过滤影响已有隐藏选项 | 新字段可选，未声明时不生效；现有 `requires_compose` / `requires_memory` 不动 |
| 新汉字导致豆腐块 | 字体子集重建 + 覆盖检查 0 缺失 + 版本化 URL |
| 学姐线结局误触发真结局状态 | 结束 id 为 `senior_shadow`，`isTrueEndUnlocked` 仍只认 `true_end` |

回滚方式：本次改动集中在 `js/script.js`、`js/engine.js`、`tests/`、文档与字体二进制；如线上异常，回退到 v3.2.4 提交并重新部署即可（存档 schema 未变）。
