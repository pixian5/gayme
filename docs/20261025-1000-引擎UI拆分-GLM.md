# v3.4.7 · 引擎 UI 拆分（P2 工程）

> 2026-10-25 · GLM

## 改动

14 个浮层渲染函数（renderSaveSlots/Config/History/Stats/Gallery/About/Keywords/
CGGallery/Flowchart/PersonalityCard/Inbox/showInboxReply/Moments/showClueTip，
合计约 2k 行）从 engine.js 迁至 **js/ui/panels.js**：

- **工厂 + ctx 注入**：`window.SakuraPanels = function (C) {...}`，engine 启动时以
  33 项 ctx（DOM 引用/状态/存档/剧本数据/回调）构建 `panels`；
- engine.js 保留薄调用（`panels.renderSaveSlots(...)` 等，17 处）；
- 交互层（showChoices/showLetter/triggerEcho/triggerScentRecall/showPerspective）
  与打字机状态机耦合深，**保留在引擎**（文档化决策）；
- `historyTab` 为工厂局部状态；`sfxGain` 经 get('sfxGain') 动态取用（避免构建时快照）；
- index.html：panels.js defer 插在 engine.js 之前；static.test 资源契约同步。

## 提取方法（沉淀）

大括号配平提取（跳过字符串/模板/注释）替代行扫描正则——嵌套对象（chars 数组、
设置面板 handler）会让行扫描正则切错位置。ctx 依赖用「engine 顶层符号 × panels
引用」的静态分析一次性补齐（bgmAudioEl/playTickAt/fadeBgm 等 7 项 + 前期 14 项）。
