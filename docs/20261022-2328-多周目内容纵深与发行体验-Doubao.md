## 三、经验与教训

1. **行号区间批量插入脚本**：先收集 blocks 再按行号替换时，若插入使文件变长，后续节点区间漂移导致错位/静默失败。修复：每个节点处理完**重新收集行号区间** + **替换结果断言**（未命中即报错退出），并先恢复文件重跑。此 bug 曾导致 39 个节点只写入 4 个且 2 个可能错位（幸未提交）。
2. **码位要查证**：⋯ 是 U+22EF（横省略号）不是 22EE（竖）；〖〗 是 3016/3017 不是 3010/3011。凭印象写区段会放行错字符。
3. **顶层 const 不进 window**：e2e/浏览器脚本访问 SCRIPT 须直接引用（全局词法绑定），`window.SCRIPT` 为 undefined。
4. **defer 会破坏 `<script src>` 精确匹配的正则**：consistency 测试正则需支持属性顺序（`<script[^>]*src=`）。
5. **写死版本号会漂移**：renderAbout 的 v2.7.8 至少漂了两轮发布；统一为 GAME_VERSION 常量并由 bump 脚本同步。
