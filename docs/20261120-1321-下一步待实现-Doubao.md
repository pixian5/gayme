# 下一步待实现（v3.4.53，2026-11-20 13:21）

## P1

1. **账号服务邮箱找回**：当前只有一次性找回码；若要降低丢码风险，可接入 SMTP 发送重置链接/验证码，并增加邮箱验证与频率限制。
2. **云存档多槽位/版本历史**：当前单包 revision；可扩展为云端快照列表（最近 N 版），支持按时间回滚，而不仅是覆盖。
3. **账号数据清理与合规**：提供「导出全部账号数据」已具备；可补注销前二次确认、审计日志自助查询、数据保留期说明。
4. **真实设备矩阵**：Safari/iPhone、Android Chrome 上验证 Secure Cookie、SameSite、PWA 离线与账号面板触控。

## P2

1. **跨域部署支持**：若账号 API 与游戏不同源，需要 `GAYME_ALLOWED_ORIGIN`、`SameSite=None; Secure`、CSP `connect-src` 与 CORS 预检联调；当前只按同源验证。
2. **限流持久化**：当前限流在进程内存，重启清零；多实例部署需 Redis/SQLite 共享计数。
3. **运维自动化**：每日定时备份 + 备份异地同步 + 磁盘告警；账号容器健康检查接入 watchdog。
4. **账号 UI 可访问性**：表单 label/aria、错误提示聚焦、键盘操作与屏幕阅读器检查。
5. **云存档压缩/加密**：整包 JSON 可 gzip 传输；如存储敏感文本，可考虑客户端加密（需权衡找回与多设备）。

## P3

1. 账号头像/昵称展示、好友/分享（若产品需要）。
2. 管理后台：账号查询、封禁、审计检索（仅在有运营需求时）。
3. 迁移到独立数据库（Postgres/MySQL）以支持多实例；当前 SQLite 足够单机。
