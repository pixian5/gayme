## 四、经验

1. **「引用不存在的配置键」是静默陷阱**：`settings.sfx` 读出来是 `undefined`，`=== false` 恒假，
   不报错、不崩溃，功能直接形同虚设。配置项要有白名单契约，读取一律走统一入口。
2. **无障碍要注意「高频更新的 live 区」**：`aria-live` 区被逐字写入时，SR 会逐字播报；
   正确做法是打字期间 `aria-busy=true`，完成后再置 `false` 让其一次性朗读。
3. **浮层的两套机制要一致**：交互锁与清理都靠「class 以 `-layer` 结尾」识别，纯 id 的浮层会
   成为漏网之鱼；新增浮层务必带上规范 class。
4. **e2e 断言要覆盖新控件的行为**，而不只是「面板能打开」——否则控件渲染正常但不生效也测不出来。
