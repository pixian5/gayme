# v3.4.16 · 玩法说明栏 + 全玩法跳过

> 2026-10-26 · GLM · 用户反馈：「很多玩法玩家根本看不明白」+「所有玩法都增加跳过」

## 一、统一说明栏（数据驱动）

**`js/game-help.js`**：89 个玩法各一套 `{ how, goal, tip }`——
- **操作**：手势/键盘/滑杆，动词开头（「上下拖动数字轮拨出四位密码。」）
- **目标**：判定口径，尽量量化（「拨出线索指向的四位数字。」）
- **提示**：只写最容易卡住的那一点（「线索是「三月、七月、二日、九时」。」）

**渲染**：`GameKit.createShell` 按 kind 自动取说明 → 左上角可折叠面板
（首次遇到展开、之后折叠，`localStorage` 记 `sakura_help_seen_v1`），
可被 `options.help` 覆盖。

## 二、全玩法跳过

说明栏底部固定「跳过这个玩法」按钮 → **中性收尾**：不写记录、不加成、直达节点 next
（复用 `cleanup + jumpNext`，与 v3.4.13 快通同一条链）。
3 个基础小游戏原本已有 `mg-skip`，本轮补全提示文案并把标签改清晰。

## 三、实现中踩到的坑（重要）

1. **说明栏不能放进 layer**：89 个玩法普遍在 `createShell` 后执行 `layer.innerHTML = ...`，
   会把刚插入的说明栏冲掉 → 改挂 `#game` 下作为兄弟节点，随 `cleanup` 一并移除；
2. **必须单例**：跳转后新玩法会挂新说明栏，旧的不清理会叠加 → `attachHelpBar`
   入口先清掉所有 `.game-help-bar`；
3. **SW 缓存干扰验证**：本地调试需 `serviceWorkers: "block"`，否则旧 SW 会喂旧脚本。
