## 一、项目全景（现状快照）

**产品形态**：443 节点视觉小说（主线 + 三女主 + 学姐线 + 双真结局 + 后日谈），89 个 GameKit 玩法 + 3 基础小游戏，12+1 结局。纯前端零构建，PWA 离线可玩。

**质量基线**：静态 42 + e2e 8 全过；pre-push 门禁拦截坏 push；服务器原子部署 + 健康检查自动回滚（cron 3 分钟，唯一正式源 oh.sbbz.tech:8080）。

**体量与资产**：代码 32k 行（engine 3.2k 纯引擎 / script 5k 数据 / games 八文件）；资产 = 8MB BGM（Ogg CC BY）+ 1.3MB CG（webp）+ 0.7MB 字体 + 图标；SW 分层缓存（核心 1.3MB 预装 / 媒体运行时）。

**多模型协作**：GLM / Doubao / DeepSeek(Trae) 三方在同一仓库接力（docs/ 100+ 篇、根目录「经验/」4 篇沉淀），版本号以 VERSION 为唯一真相、冲突顺延——机制已跑顺（v3.2.1→v3.4.2 无撞车事故）。

## 三、下一步开发建议（详细）

### 优先级 P0 · 发行闭环（建议 v3.4.3~v3.4.4，两天内）

1. **修 pack-itch.sh**：打包清单加 `audio`（zip 会到 ~10MB，可接受；或 itch 上传时分「含 BGM/轻量版」两个包）。
2. **itch.io 实际上架**（需你操作，素材全齐）：`bash tools/pack-itch.sh` → itch 上传 → 按文档填文案/封面 → 发布页加链接。
3. **国内访问加速（新建议）**：`play.sbbz.tech` 子域走 Cloudflare proxied → Origin Rule 指向 8080。CF 支持代理 8080 端口，且 sbbz.tech 已在 Cloudflare DNS；对国内试玩者可显著提速静态资源（BGM 大文件也可经 CF 缓存）。需你确认是否接受流量经 CF。
4. **试玩反馈回流**：gitee issues 入口已有；可在 itch 页面加同链接。

### 优先级 P1 · 内容与质量（v3.4.5~v3.4.8）

1. **loopText 第四批（筛选制）**：只补「叙事承载」节点——女主线 good 完整链（sy_10~15_good 等已部分覆盖，补 xz/sn good）、d2/d3/d4 共通线关键对话（如 d2_noon_2~10、d3_noon_2~6）、prologue 情感节点。目标 120→155，**跳过 d6~d15 玩法提示节点**（prompt 类文本多周目重复感低）。
2. **「她说」密度抽检**：双排比已清零，但部分节点仍有单次「她说」与相邻节点连用——按「连续 3 节点内不重复同一句式」抽查 20 处微调（不做全局正则替换）。
3. **e2e firefox 纳入门禁**：`BROWSER=firefox npm run test:e2e` 手动跑一次全量；通过后 pre-push 的 PREPUSH_E2E 同时跑双内核（e2e 仅 7 秒，成本可忽略）。
4. **回响扩展**：自由回信（msg_* 类型）内容也进回响 Tab（当前只有 choice.value）；按线路分组。

### 优先级 P2 · 工程（v3.4.9~v3.4.10）

1. **引擎 UI 拆分**：`js/ui/panels.js`（存/读/设置/历史/图鉴/统计/新手引导，约 2k 行）——移动改动零风险，e2e 8 项兜底；engine.js 降到 ~1.2k 行。
2. **P1-6 重评**：位图 CG 后「背景预取」结论需重验（webp 解码也有成本）——低优先。
3. **偏好同步**：reduce-motion 已做设置开关（v3.3.12）+ 系统跟随（v3.2.0）——验证两者优先级逻辑（设置 > 系统）是否如预期。

- **多模型接力**：并行开发时以 git 为准、读最新进度快照的约定已跑顺，保持「接手前必拉取」纪律即可。

## 四、一句话总结

产品与工程都已达「可对外分发」水位；下一阶段的重点**不在写更多代码，而在让真实玩家进来**——修掉 itch 打包缺口、做完 CF 加速与上架，把试玩反馈（同质化、节奏、难度）作为 Phase 4 的主输入。
