# v3.3.13 存档增强与新手引导（DeepSeek）

日期：2026-10-24 10:54 · 模型：DeepSeek · 版本：v3.3.13

## 背景

按《下一步开发完整计划》Phase 1 收尾，本轮实现 **P1-4 存档增强** 与 **P1-7 新手引导**。

## 一、P1-4 存档增强

| 项 | 说明 |
|---|---|
| 槽位重命名 | 存档数据新增 `name` 字段；`Saves.renameSave(slot, name)`（≤20 字）；存档面板「命名」按钮（`prompt` 输入，留空清除）；标题优先显示自定义名 |
| 单槽导出 | `Saves.exportSlot(slot)` 返回该槽深拷贝；「导出」按钮下载 `sakura-save-slotN.json` |
| 单槽导入 | `Saves.importSlot(slot, data)`（校验 `nodeId` 为非空字符串）；「导入」按钮选本地 JSON 写入指定槽位，失败给提示 |
| 兼容 | 旧存档无 `name` 字段 → 回退显示 `sceneLabel`；新增字段对 `_saveSaves` 透明 |

原有「导出全部数据 / 导入备份」的全局方案保留，单槽方案便于精细备份与跨设备迁移。

## 二、P1-7 新手引导

- 新档**首次**进入时弹出 `.tutorial-layer` 引导浮层（点击 / 空格 / 回车 / Esc 均可关闭）；
- 内容：推进剧情的点击与快捷键、选项/回信的键盘操作、快存/自动/快进、顶栏功能入口；
- 用 `Saves.getFlag("tutorialSeen")` 去重，**只出现一次**；浮层 class 以 `-layer` 结尾，
  自动纳入交互锁与返回标题清理。

## 四、经验

- **新档一次性引导要落盘「已看」标记**，否则每次新档都弹；同时该标记属于玩家进度，放 `flags` 合适。
- **测试与「首次」逻辑冲突时先置标记**：e2e 多处 `newGame`，需在用例开头把 `tutorialSeen` 置真，
  再单写一个用例重置后验证引导，避免引导浮层（交互锁）阻断其它步骤。
- **单槽导入要校验 `nodeId`**：坏存档直接拒绝，比读档时崩溃更友好。
