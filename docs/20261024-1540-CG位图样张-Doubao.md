> 记录时间：2026-10-24 15:40
> 版本：v3.3.16（开发测试版 · Demo）

## 一、目的

现有 11 张 CG 与 5 张立绘都是内联 SVG 字符画，能表达构图与配色，但表现力有限。
本轮不直接批量替换，而是**先做一张样张定风格**：确认画面语言（日式校园、水彩插画、
暖色夕阳）、人物形象与「樱时信笺」气质一致后，再批量生产。

## 二、样张内容

- CG：`cg_meet_shiyu`「走廊的初次相遇」（林诗雨，序章关键场景）
- 文件：`assets/cg/cg_meet_shiyu_sample.jpg`（1600×960，355KB，JPEG q82）
- 画面：黄昏走廊、鞋柜、窗外樱花、两人隔着几步对视，近景少女攥着信纸
- 生成方式：文生图（8 段式提示词：用途 + 场景 + 人物 + 光线 + 构图 + 风格 + 色板 + 负面约束）

## 三、工程改动（为批量做准备）

| 改动 | 说明 |
|---|---|
| `CGS` 数据 | 每条新增可选 `img` 字段，**优先于 `svg`**，缺省时行为不变 |
| `cgArt(cg)` | 统一渲染入口：有 `img` 输出 `<img loading="lazy" alt="标题">`，否则回落内联 SVG |
| `css/style.css` | `.cg-card img` 与 `.cg-viewer-art img` 补齐样式（宽度 100%、大图 `max-height:74vh`、`object-fit:contain`） |
| `sw.js` | 预缓存加入位图（离线可看） |
| 压缩 | `sips -Z 1600` + q82：531KB → 355KB；查看器最大显示高度 666px，1600 宽已足够清晰 |

这样后续批量只需「产图 → 放进 `assets/cg/` → 在 CGS 加一行 `img`」，不改任何渲染逻辑；
未替换的 CG 继续用 SVG，可渐进上线。
