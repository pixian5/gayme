## 三、后处理管线（三件事，缺一不可）

1. **去底部白色 letterbox**：生成图常为 2560×1536 且底部带纯白条
   （festival 58px、xiazhi 73px、xiazhi_good 98px、shiyu_good 56px、senior_shadow 52px）。
   做法：`scale=1:H` 灰度列 → Node 检测自底部起的连续亮行（阈值 250，上限 10% 高度）
   → 得到有效高度 → 按 5:3 居中裁宽。
2. **统一尺寸**：`scale=1600:960:flags=lanczos -q:v 3`，体积 115–355KB，图鉴卡片等高对齐。
3. **局部修补**：「终点线」第 3 版仍在裙腰处露出一条肤色，用像素级修补覆盖（见下节）。

## 四、腰部露肤的像素修补（本轮唯一需要人工修图的案例）

生成失败点的共同原因：提示词写了「上衣下摆盖住裙腰」，模型仍会在腰线处留一条肤色。

修补流程（临时脚本，未入库）：

1. 放大裁剪定位腰腹区域（2560×1536 下的 x 1300–1500 / y 975–1030）；
2. 宽松暖色判据（`r-b>18 && r>120 && b<215`）逐列扫描，得到需要覆盖的连续段，
   上下各扩 7 / 5 行，盖住抗锯齿边缘（**只扩首段会漏掉被轮廓线切开的碎片**）；
3. 填充色 = 该列「裙腰带下方区间」的平均色，向上做 0.55→1.0 的平滑渐变，
   顶部压暗模拟「衣摆投影阴影」，视觉上就是裙腰被上衣遮住；
4. 用羽化掩膜（GaussianBlur 2.0）把填充层与底图合成，再对填充层做 0.9 模糊消除拼接线；
5. 修完复查一次：`0` 个残留暖色像素；再整图目视 + 缩放到 1600×960 复检。

第 2 版（只填首段）残留 2 个橙色碎片，第 3 版改为「逐列全部连续段」后清零。

## 七、经验

- **位图迁移只改数据，不改渲染**：`img` 字段优先、`svg` 兜底的设计，让 11 张替换是纯数据改动，
  回滚只需删字段，风险极低。
- **生图必须统一后处理**：同一批图尺寸/白边各不相同，不统一会出现卡片高低错落。
- **人物一致性靠显式外观锚点**：每张提示词都复述发色/瞳色/校服，比只写名字稳定得多。
- **模型对「遮挡关系」不稳定**：涉及「衣摆盖住腰」这类接触关系，宁可预留 1–2 次重生成，
  小面积瑕疵用像素修补比再生成更快更可控。
- **修补要用「全部连续段」而不是「首个连续段」**：轮廓线把肤色切成多段时，后者会留碎片。
