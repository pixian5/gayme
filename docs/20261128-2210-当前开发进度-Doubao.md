## 本版做了什么

**空闲运行巡检**。盒子 cron 每 3 分钟本来就会跑部署脚本；本版让它在「没有新提交」时也检查 8090 首页、账号 `/api/health` 的 database 与 2096 证书剩余天数。异常按类型推「运行告警」，恢复后清标记并推「运行恢复」；同一故障只推一次，异常期间不刷屏。没有账号容器或 2096 未开 TLS 时对应项跳过，避免误报。
