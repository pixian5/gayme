# v2.8.4 · 玩法模板减量（第 1 批：手作与器物 13 个玩法）

> 时间：2026-09-30 02:49
> 版本：v2.8.3 → v2.8.4
> 目标：把 engine.js 里 76 个「玩法模板重复」分批迁出，改用 GameKit 统一外壳与收尾。

## 一、为什么要做

`js/engine.js` 长期是单文件巨石：16172 行 / 590,035 字符，其中 76 个玩法 runner 各自手抄同一套样板。
量化后（改动前的统计）：

| 重复样板 | 出现次数 | 每处行数 | 潜在可减 |
|---|---|---|---|
| 序言：`dialogBox.classList.add("hidden")` + 建 layer + `className` + `id` | 75 | 5 | ~300 行 |
| 效果块：`add` + `personality` + `memory` 三段式 | 72 | 12 | ~790 行 |
| 尾部：`layer.remove()` + `SCRIPT` 查表 + `gotoNode` | 77 | 5 | ~380 行 |
| `MutationObserver` 清理块 | 56 | 8 | ~450 行 |
| 手写结果面板 `<prefix>-reading` | 66 | 9 | ~530 行 |

合计约 2000~2400 行的重复。`js/gamekit.js`（v2.8.0 起）已经为这次迁移准备好：
`createShell()` 接管序言与清理（用 `GameLifecycle` + `onCancel` 取代各玩法自建的 `MutationObserver`），
`finish()` 接管效果块 + 结果面板 + 跳转；且现存玩法的面板类名（`ch-reading`、`sp-reading`…）
本来就和 `showReading(prefix)` 生成的完全一致。

### 3.3 每个玩法的改写方式

```js
// 旧写法（每个玩法重复 ~30 行样板）
el.dialogBox.classList.add("hidden");
const layer = document.createElement("div");
layer.className = "wx-layer"; layer.id = "wx-layer";
layer.innerHTML = `...`;
// ...交互主体...
Saves.saveWxRecord(currentNodeId, ...);
if (matched.add) { applyAdd(matched.add); updateHeartBar(); }
if (matched.personality) { for (const dim in matched.personality) Saves.addPersonality(dim, matched.personality[dim]); }
if (matched.memory) { if (!Saves.isMemoryUnlocked(matched.memory.id)) { Saves.saveMemory(...); flashHint(...); } }
const reading = document.createElement("div");
reading.className = "wx-reading";
reading.innerHTML = `<div class="wx-reading-title">${matched.label || "解读"}</div>
  <div class="wx-reading-text">${matched.text || ""}</div>
  <button class="wx-reading-close">继续</button>`;
reading.querySelector(".wx-reading-close").onclick = () => { reading.remove(); layer.remove(); ... gotoNode(jumpTo); };
layer.appendChild(reading);
const mo = new MutationObserver(() => { if (!document.body.contains(layer)) { aborted = true; mo.disconnect(); } });
mo.observe(document.getElementById("game"), { childList: true });
document.getElementById("game").appendChild(layer);
```

```js
// 新写法
const shell = createShell({ kind: "wx", prefix: "wx", nodeId, onCancel: () => { aborted = true; } });
const layer = shell.layer;
layer.innerHTML = `...`;
// ...交互主体保持不变...
confirmBtn.onclick = () => {
  if (aborted) return;
  aborted = true; confirmBtn.disabled = true;   // 防重入语句原样保留
  // ...判定逻辑不变...
  shell.finish({
    ...matched,
    label: `${matched.label || "解读"} · 补充说明`,
    record: () => Saves.saveWxRecord(nodeId, ...),
  });
};
```

**行为等价性要点**：`finish()` 在做完 `record` → `add` → `personality` → `memory` 后弹面板，
点「继续」才 `cleanup()` 并跳转，与原逻辑同序；`onCancel` 承担原来 `MutationObserver` 的清理动作，
在读档 / 返回标题 / 关闭浮层时都会触发，且幂等。
