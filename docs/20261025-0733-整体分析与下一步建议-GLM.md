## 二、本轮数据体检的新发现

### 发现 1：e2e 只采样 12 个节点（最大的质量盲区）★★★★

e2e 的 12 次 `gotoNode` 覆盖 8 个玩法文件各 1-2 个 + 真结局链 + 存读档——
但 443 个节点中的 **431 个从未在真实浏览器里被执行过**。历史教训：v2.9.0 曾
「31 项测试全绿但运行时必崩」（引擎符号不可达），这类回归只有运行时能抓。
数据侧：106 个含玩法/互动字段的节点、443 条 text 渲染、全部 bg 场景类、
`chars`/`perspective`/`loopText`/`keyword` 组合——任何一处数据笔误都可能
只在特定节点触发。**全图运行时走查是当前唯一系统性盲区。**

### 发现 2：PWA 无「新版本可用」提示 ★★★

SW 采用「导航网络优先 + 资源缓存优先」：新版本部署后，玩家要**下一次完整访问**
才拿到新 index.html，且已缓存资源靠 stale-while-revalidate 慢慢换血——
经常更新的游戏，玩家可能长时间停留在旧版而不知情。缺一个
`registration.update()` 轮询 + `controllerchange` → 「✦ 新版本已就绪，刷新生效」提示。

### 发现 3：loopText 剩余 311 节点的边际价值分层 ★★

| 前缀 | 缺口 | 价值评估 |
|---|---|---|
| d 链 | 195 | **低**——中位 text 仅 65 字符，多为玩法 prompt（「她递来…你试着…」），多周目重复感弱；其中叙事型节点（d4 情感节点等）已在批次三覆盖 |
| afterword | 21 | 中——后日谈是破环玩家的「第二季」，值得终批 |
| prologue | 17 | 中——二周目重读序章的既视感是好题材，但 4 个高信号节点已覆盖 |
| sn/xz/sy | 45 | 低——剩余为转场短句（choice 后的第一句回应） |
| letter/route/common | 11 | 低——信件 UI 节点与线路入口 |
| **合计可做终批** | **~25（afterword 全部 + prologue 情感 5 + 路线入口 4）→ 132→157** | 之后宣布 loopText 完工 |

### 发现 4：学姐线（23 节点）未经第三方通读 ★★

v3.3.0 由 Doubao 新增，有数据契约测试与 e2e 入口断言，但**没有过一次
叙事级全文走查**（类似我 v3.0.1 对 414 节点做的那种：时间线/知识揭示顺序/
角色行为合理性）。学姐线承担「影子设定」的关键解释，与真结局咬合最深，
是当前内容侧最大的未验证面。

## 三、下一步开发建议（执行级）

### P0 · 质量盲区补位（v3.4.9~v3.4.11，全部自主可做）

**P0-1 e2e 全图运行时走查（v3.4.9）** ★最高优先
- 新增 `tests/browser/graph.e2e.mjs` + `npm run test:graph`：
  本地起服务 → `window.__game.gotoNode()` 遍历全部 443 节点 → 每节点断言
  （无 pageerror/console error；玩法节点浮层挂载后即清理；普通节点 dialog-box 激活）；
- 预计 443 × ~80ms ≈ 40 秒，**不进 pre-push**（`PREPUSH_GRAPH=1` 可选），进「大版本前必跑」流程；
- 输出报告：每个节点的执行结果清单，坏节点直接点名。
- 预期收益：消灭「数据侧 OK 运行时崩」的整类风险，且为后续任何内容改动提供安全网。

**P0-2 SW 新版本提示（v3.4.10）**
- 每 5 分钟 `registration.update()`；`controllerchange` 时 flashHint
  「✦ 新版本已就绪，刷新页面生效」；PWA 场景下这是玩家获取更新的唯一通道。

**P0-3 游戏内更新日志（v3.4.10 合并交付）**
- 「关于」页加「版本更新」折叠区：近 5 版一行摘要（从 engine 头注释自动生成
  或 CHANGELOG 常量）；itch 分发页文案同步引用。

### P1 · 内容收口（v3.4.11~v3.4.12）

**P1-1 loopText 终批（v3.4.11）**：afterword 21 + prologue 情感 5 + 路线入口 4
→ 132→~157，随后**宣布 loopText 计划完成**（d 链 prompt 类与转场短句明确不做，理由入档）。

**P1-2 学姐线叙事级走查（v3.4.12）**：通读 23 节点全文，按 v3.0.1 同标准

无问题归档结论。

## 五、一句话总结

Phase 3 之后项目已无已知缺陷；剩余工作的本质是**「把安全网从采样升级为全量」（全图走查）+「让玩家永远在最新版」（SW 提示）+「内容侧最后两个收口」（loopText 终批、学姐线走查）**——全部自主可做，约两个工作单元；之后项目进入「等素材、等上架操作、等玩家反馈」的纯外部依赖期。
