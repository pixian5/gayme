## 经验提炼

1. **测试基建也要过 CSP**：`page.evaluate("字符串表达式")` 在 `script-src 'self'` 下等同 eval，
   会被拦截；改用函数对象/帧上下文函数驱动。字符串形式在慢页面还会"假通过"。
2. **分享卡片必须同源自洽**：历史域名失效后 301→HTTPS→525，三条 meta 各指一处会静默丢图；
   契约改为「同源」断言 + 发布后 `check-meta.mjs` 校验。
3. **低配设备瓶颈常是 backdrop-filter**：默认开、可关闭，是兼顾视觉与帧率的最小改动。
4. **字体子集要跟随字符集重建**：文本增长后不复检会回退系统字体（本次一次补回 127 字）。
5. **文档债会累积**：四天 8 个版本只有 1 篇追加记录；建议每版至少落一篇
   或按批次合并，并在 README 保留「当前状态」指针。
