## 二、迁移方式：host 桥 + keepDialog（与标准批次不同）

直跳型玩法无结果面板、收尾形态各异（条件分派跳转 / 延迟跳转 / 评分跳转），
不适合强行套 `shell.finish()`。本批改用**最小重写**策略，行为逐行等价：

- GameKit 新增：`host` 宿主桥对象直接暴露（直跳型经 `host.applyAdd / host.updateHeartBar /
  host.gotoNode` 调用宿主能力）；`createShell({ keepDialog: true })` 保持 collage/photo/rhythm
  原本不隐藏对话框的行为。
- 函数体除以下机械替换外**原样保留**：签名→register、layer 创建→shell.layer、
  `layer.remove()`→`shell.cleanup()`（幂等并注销生命周期）、引擎符号→host.*、
  `state.currentBg`→`bgNow()`（经背景层 DOM 等价读取）、`el.bgOverlay`→按 id 读取。
- MutationObserver（rhythm/spectrum）与 document 监听（photo）→ `onCancel` 钩子。

## 三、顺手修复（读档 / 返回标题后的残留跳转 bug）

- **rhythm / silenceChoice 的延迟跳转**：原实现 setTimeout 回调在读档 / 返回标题后仍会触发
  `gotoNode`（把剧情从标题页拉走）。迁移后回调首行加 `if (shell.signal?.aborted) return;`，
  经生命周期 AbortController 拦截。
- **matchConstellation / matchPuzzle / matchPerfume**：与 v2.9.0 同类的「引擎符号不可达」
  隐患（nature.js / perception.js 在调用），本轮一并移入对应 games 文件。
  交叉扫描确认：全部 8 个 games 文件对引擎内部函数的引用只剩合法的 GameKit 解构
 （flashHint / escapeHtml）。
