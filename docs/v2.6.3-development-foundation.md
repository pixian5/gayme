# v2.6.3 开发基础设施与复核记录

## 本轮完成

- 增加 Node 原生测试基座，覆盖静态资源、剧情图引用与主线可达性、存档边界、损坏数据、写入失败回滚、备份导入导出和生命周期令牌。
- 增加存储 schema 元数据（v3），提供导出/导入 JSON，并在导入失败时按原始 raw 值回滚；缓存通过 `storage` 事件失效。
- 将小游戏浮层注册到统一 `GameLifecycle`，新游戏、读档和返回标题时统一取消异步交互。
- 补充键盘焦点可视样式、ARIA 状态播报、菜单按钮名称和浮层焦点恢复，配置页提供数据备份入口。

## 验证记录

- `npm test`：11 项通过。
- `npm run test:syntax`：全部 JavaScript 语法通过。
- `git diff --check`：通过。
- Python 静态 HTTP server：`index.html`、CSS 与全部 JavaScript 资源均返回 200。

## 后续建议

1. 在非热点网络环境补充真实浏览器端 Playwright 测试，覆盖移动端点击、键盘焦点陷阱、小游戏计时器和导入文件选择器。
2. 将剧情节点定义与渲染逻辑拆分为独立模块，逐步减少 `engine.js` 的全局耦合。
3. 为存储 schema 增加显式迁移函数表和导入数据大小上限，避免未来版本升级时一次性处理过多旧格式。
